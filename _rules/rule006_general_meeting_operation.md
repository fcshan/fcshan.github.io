# 翡翠山城别墅区业主大会会议操作手册(模板，非正式)

**手册编号：** FCSC-MAN-001  
**适用对象：** 业主委员会全体成员、物业服务企业会务人员  
**制定日期：** 2026年X月X日  
**版本：** v1.0  

---

## 第一章 手册说明

### 1.1 编制目的

本手册为翡翠山城别墅区业主委员会提供业主大会会议的标准化操作流程，适配**微信群议事**和**粤省事电子投票**的实际场景，确保会议召集、讨论、投票、计票、公示等环节合法合规、公开透明、可追溯。

### 1.2 适用范围

本手册适用于以下会议类型：

| 会议类型 | 说明 |
|:---------|:-----|
| **首次业主大会** | 小区交付后或前期物业届满后召开的首次会议 |
| **定期业主大会** | 每年至少召开一次的例行会议 |
| **临时业主大会** | 遇重大事项或紧急情形临时召集的会议 |
| **专项表决** | 针对特定事项的粤省事电子投票 |

### 1.3 基本原则

| 原则 | 要求 |
|:-----|:-----|
| **程序合法** | 严格遵循《民法典》《物业管理条例》《业主大会议事规则》的程序要求 |
| **全程留痕** | 每个环节形成电子或书面记录，截图、录像存档 |
| **多方见证** | 邀请街道办事处、社区居委会、业主代表全程监督 |
| **即时公开** | 会议信息、投票进度、结果公示第一时间在微信群和网站发布 |
| **技术兜底** | 电子投票为主，书面投票为辅，确保每位业主都能参与 |

## 第二章 会议筹备阶段

### 2.1 确定会议议题

#### 2.1.1 议题征集

| 征集渠道 | 征集时限 | 责任人 | 接收方式 |
|:---------|:---------|:-------|:---------|
| 业委会委员提议 | 会前30日 | 全体委员 | 微信群/腾讯会议 |
| 业主联名提议（20%以上） | 会前30日 | 宣传委员 | 微信群私信/邮箱/书面 |
| 街道办事处/社区居委会提议 | 会前20日 | 主任 | 电话/微信/书面 |
| 物业服务企业提议 | 会前20日 | 物业经理 | 微信群/书面 |

#### 2.1.2 议题审核

业委会会议（腾讯会议或线下）对征集的议题进行审核：

| 审核要点 | 标准 |
|:---------|:-----|
| **合法性** | 议题内容不得违反法律法规强制性规定 |
| **权限性** | 议题应当在业主大会职权范围内 |
| **可行性** | 议题应当具有可操作性，有明确方案或选项 |
| **必要性** | 议题应当确有必要由业主大会决定 |

#### 2.1.3 议题确定

| 步骤 | 内容 | 时限 | 线上操作 |
|:-----|:-----|:----:|:---------|
| 1 | 业委会会议讨论确定议题清单 | 会前25日 | 腾讯会议表决 |
| 2 | 向街道办事处报备议题 | 会前23日 | 微信发送+书面送达 |
| 3 | 街道办事处审核反馈 | 会前20日 | 微信/电话反馈 |
| 4 | 最终确定议题，编制会议方案 | 会前18日 | 微信群发布草案 |

### 2.3 准备会议材料

#### 2.3.1 材料清单

| 材料类型 | 具体内容 | 形式 | 责任人 |
|:---------|:---------|:-----|:-------|
| **会议通知** | 微信群公告版、公众号图文版、短信版 | 电子 | 宣传委员 |
| **议题说明** | 每个议题的背景、方案、利弊分析、数据依据 | PDF+网页 | 相关委员 |
| **粤省事操作指南** | 图文步骤、操作视频、常见问题 | 图文+视频 | 宣传委员 |
| **书面表决票** | 按议题定制，编号管理（备用） | 纸质 | 宣传委员 |
| **委托书** | 电子委托说明+书面委托模板 | 电子+纸质 | 宣传委员 |
| **业主名册** | 应参会业主清单（脱敏） | 电子 | 宣传委员 |
| **FAQ文档** | 预设业主常见问题及答复 | 电子 | 全体委员 |

#### 2.3.2 粤省事投票发起

| 步骤 | 操作 | 责任人 | 时限 |
|:-----|:-----|:-------|:----:|
| 1 | 登录粤省事"业主决策电子投票"系统 | 宣传委员 | 会前15日 |
| 2 | 发起新投票，填写会议基本信息 | 宣传委员 | 会前15日 |
| 3 | 录入议题内容（标题、说明、选项） | 宣传委员 | 会前14日 |
| 4 | 设定投票起止时间 | 宣传委员 | 会前14日 |
| 5 | 提交审核（平台审核通常需1-3日） | 宣传委员 | 会前13日 |
| 6 | 审核通过后，测试投票流程 | 业委会委员 | 会前10日 |
| 7 | 确认投票正常开启 | 宣传委员 | 会前7日 |

> **测试要求：** 至少2名业委会委员使用不同手机进行测试投票，确认流程顺畅、选项正确、提交成功。

### 2.4 会议通知

#### 2.4.1 通知时限

| 会议类型 | 通知期限 | 法律依据 |
|:---------|:---------|:---------|
| 定期会议 | 召开15日前 | 《业主大会议事规则》第八条 |
| 临时会议 | 召开15日前 | 《业主大会议事规则》第八条 |
| 首次会议 | 召开15日前 | 《物业管理条例》第十四条 |

#### 2.4.2 通知方式与送达确认

| 方式 | 具体操作 | 送达确认 | 优先级 |
|:-----|:---------|:---------|:------:|
| **微信群公告** | 业委会主任发布群公告，@全体成员 | 保留群公告截图、阅读人数记录 | ★★★ |
| **微信公众号推送** | 通过小区公众号发布图文通知 | 保留推送记录、阅读量 | ★★★ |
| **短信通知** | 向预留手机号发送短信（含投票链接） | 保留短信平台发送回执 | ★★☆ |
| **公告栏张贴** | 在小区主要出入口、各楼栋单元门口张贴 | 拍照存档，记录时间地点 | ★★☆ |
| **网站公示** | 在GitHub Pages公示站发布 | 保留网页快照 | ★★☆ |
| **电话通知** | 对老年业主、长期未参与业主电话通知 | 记录通话时间、内容 | ★☆☆ |

> **送达规则：** 以上方式同时采用三种以上即视为有效送达。微信群公告发布后即视为送达，业主未查看不影响会议效力。

## 第五章 计票公示阶段

### 5.1 计票统计

#### 5.1.1 统计规则

| 项目 | 计算方式 | 数据来源 |
|:-----|:---------|:---------|
| **参与率（面积）** | 参与表决业主专有部分面积之和 ÷ 小区专有部分总面积 | 粤省事导出数据 |
| **参与率（人数）** | 参与表决业主人数 ÷ 小区业主总人数 | 粤省事导出数据 |
| **同意率（面积）** | 同意业主专有部分面积之和 ÷ 参与表决业主专有部分面积之和 | 粤省事导出数据 |
| **同意率（人数）** | 同意业主人数 ÷ 参与表决业主人数 | 粤省事导出数据 |

#### 5.1.2 有效性判定

| 判定标准 | 要求 |
|:---------|:-----|
| **会议有效** | 面积参与率 ≥ 2/3 且 人数参与率 ≥ 2/3 |
| **决议通过（一般事项）** | 会议有效，且面积同意率 > 1/2 且 人数同意率 > 1/2 |
| **决议通过（重大事项）** | 会议有效，且面积同意率 ≥ 3/4 且 人数同意率 ≥ 3/4 |
| **决议不通过** | 未达到上述比例 |

> **系统优势：** 粤省事平台自动校验参与率和同意率，但业委会应当人工复核，确保无误。

## 第七章 应急情形处理

### 7.1 粤省事系统故障

| 故障类型 | 处理方式 |
|:---------|:---------|
| **系统无法登录** | 引导业主稍后重试，同时启动书面表决备用方案 |
| **投票提交失败** | 记录业主信息，系统恢复后通知重新投票 |
| **数据导出异常** | 联系粤省事客服（12345），同时人工统计核对 |
| **系统长时间故障** | 报街道办事处，申请延期投票或改为书面表决 |

### 7.2 微信群异常

| 情形 | 处理方式 |
|:-----|:---------|
| **微信群被封** | 立即启用备用群（提前建立的"翡翠山城业主群2"），通过短信、电话通知业主 |
| **群主账号异常** | 提前设置2-3名管理员，可接管群主权限 |
| **恶意投诉群** | 保留群规、聊天记录作为证据，向微信申诉，同时启用备用群 |
| **群内冲突升级** | 私信调解，必要时暂时禁言冲突双方，避免影响正常议事 |

### 7.3 网络故障

| 情形 | 处理方式 |
|:-----|:---------|
| **小区网络中断** | 联系运营商抢修，同时通过短信、电话通知业主 |
| **公示网站无法访问** | 检查GitHub Pages状态，启用备用域名或Gitee镜像 |
| **业主个人网络问题** | 建议切换移动数据，或采用书面表决 |

### 7.4 业主投诉与质疑

| 情形 | 处理方式 |
|:-----|:---------|
| **质疑电子投票安全性** | 说明粤省事为政府官方平台，数据加密，可查询个人投票记录 |
| **质疑微信群议事效力** | 明确微信群仅为议事参考，正式表决以粤省事为准 |
| **质疑业委会操纵结果** | 邀请街道办事处、社区居委会监督，公开计票过程 |
| **质疑通知不到位** | 出示通知记录（群公告截图、短信回执、张贴照片） |
