# 翡翠山城别墅区业主大会会议操作手册(模板，非正式)

**手册编号：** FCSC-MAN-001  
**适用对象：** 业主委员会全体成员、物业服务企业会务人员  
**制定日期：** 2026年X月X日  
**版本：** v1.0  

---

## 第一章 手册说明

### 1.1 编制目的

本手册为翡翠山城别墅区业主委员会提供业主大会会议的标准化操作流程，确保会议召集、召开、表决、计票、公示等环节合法合规、公开透明、可追溯。

### 1.2 适用范围

本手册适用于以下会议类型：

| 会议类型 | 说明 |
|:---------|:-----|
| **首次业主大会** | 小区交付后或前期物业届满后召开的首次会议 |
| **定期业主大会** | 每年至少召开一次的例行会议 |
| **临时业主大会** | 遇重大事项或紧急情形临时召集的会议 |
| **专项表决** | 针对特定事项的书面征求意见表决 |

### 1.3 基本原则

| 原则 | 要求 |
|:-----|:-----|
| **程序合法** | 严格遵循《民法典》《物业管理条例》《业主大会议事规则》的程序要求 |
| **全程留痕** | 每个环节形成书面记录，拍照或录像存档 |
| **多方见证** | 邀请街道办事处、社区居委会、业主代表全程监督 |
| **即时公开** | 会议信息、表决结果第一时间在公示网站和公告栏发布 |

## 第二章 会议筹备阶段

### 2.1 确定会议议题

#### 2.1.1 议题征集

| 征集渠道 | 征集时限 | 责任人 |
|:---------|:---------|:-------|
| 业委会委员提议 | 会前30日 | 全体委员 |
| 业主联名提议（20%以上） | 会前30日 | 宣传委员接收登记 |
| 街道办事处/社区居委会提议 | 会前20日 | 主任对接 |
| 物业服务企业提议 | 会前20日 | 物业经理提交 |

#### 2.1.2 议题审核

业委会会议对征集的议题进行审核，确定是否列入会议议程：

| 审核要点 | 标准 |
|:---------|:-----|
| **合法性** | 议题内容不得违反法律法规强制性规定 |
| **权限性** | 议题应当在业主大会职权范围内 |
| **可行性** | 议题应当具有可操作性，有明确方案或选项 |
| **必要性** | 议题应当确有必要由业主大会决定 |

#### 2.1.3 议题确定

| 步骤 | 内容 | 时限 |
|:-----|:-----|:----:|
| 1 | 业委会会议讨论确定议题清单 | 会前25日 |
| 2 | 向街道办事处报备议题 | 会前23日 |
| 3 | 街道办事处审核反馈 | 会前20日 |
| 4 | 最终确定议题，编制会议方案 | 会前18日 |

### 2.3 准备会议材料

#### 2.3.1 材料清单

| 材料类型 | 具体内容 | 份数 | 责任人 |
|:---------|:---------|:----:|:-------|
| **会议通知** | 张贴版、电子版、上门送达版 | 200+ | 宣传委员 |
| **表决票** | 按议题定制，编号管理 | 200+ | 宣传委员 |
| **议题说明** | 每个议题的背景、方案、利弊分析 | 200+ | 相关委员 |
| **签到表** | 业主姓名、房号、面积、联系方式 | 2份 | 宣传委员 |
| **委托书** | 空白委托书模板 | 50份 | 宣传委员 |
| **业主名册** | 应参会业主清单（脱敏） | 2份 | 宣传委员 |
| **投票箱** | 带锁投票箱，配封条 | 2个 | 物业 |
| **封条** | 一次性封条，编号管理 | 10张 | 物业 |

#### 2.3.2 表决票制作

表决票应当符合以下要求：

| 要求 | 说明 |
|:-----|:-----|
| **统一印制** | 由业委会指定印刷厂印制，不得自行打印 |
| **编号管理** | 每张表决票有唯一编号，与业主名册对应 |
| **防伪标识** | 加盖公章或专用防伪标记 |
| **内容清晰** | 议题表述准确，选项明确（同意/反对/弃权） |
| **预留空间** | 预留业主签字、房号、日期填写空间 |

> **安全提示：** 表决票印制完成后，应当由2名以上委员共同清点、封存，存放于安全地点，直至会议召开。

#### 2.4.1 通知时限

| 会议类型 | 通知期限 | 法律依据 |
|:---------|:---------|:---------|

| 临时会议 | 召开15日前 | 《业主大会议事规则》第八条 |

#### 2.4.2 通知方式

| 方式 | 具体操作 | 留痕要求 |
|:-----|:---------|:---------|

### 3.3 会议主持（电子投票模式）

#### 3.3.1 主持流程

电子投票模式下，会议主持主要在投票开始前和结束后进行：

| 时段 | 内容 | 主持人 | 方式 |
|:-----|:-----|:-------|:-----|
| 投票开始前 | 发布投票通知、操作指南、议题说明 | 业委会主任 | 微信群+网站公示 |
| 投票期间 | 解答业主疑问、跟进投票进度、发送提醒 | 业委会委员 | 微信群+私信 |
| 投票结束后 | 宣布投票截止、公布结果、说明后续安排 | 业委会主任 | 微信群+网站公示 |

#### 3.3.2 主持要点

| 要点 | 要求 |
|:-----|:-----|
| **提前公告** | 投票开始前3天、1天、当天各发布一次提醒通知 |
| **操作指引** | 提供清晰的粤省事投票操作截图或视频教程 |
| **及时答疑** | 投票期间安排专人回复业主咨询（早9:00-晚21:00） |
| **进度通报** | 投票期间可定期通报参与率（不显示具体投票内容） |
| **结果公开** | 投票结束后第一时间在公示网站公布结果 |

### 3.4 业主讨论

#### 3.4.1 发言规则

| 规则 | 要求 |
|:-----|:-----|
| **举手申请** | 业主举手示意，经主持人允许后发言 |
| **限时发言** | 每人每次发言不超过3分钟，同一议题每人不超过2次 |
| **就事论事** | 围绕议题发言，不得人身攻击、偏离主题 |
| **尊重他人** | 他人发言时不得打断、起哄 |
| **书面意见** | 时间有限时，可提交书面意见，会后整理公示 |

#### 3.4.2 答疑规范

| 情形 | 处理方式 |
|:-----|:---------|
| 业主提问涉及议题内容 | 由相关委员当场答复，答复应当客观、准确 |
| 业主提问涉及数据依据 | 出示原始数据、检测报告、合同文本等 |
| 业主提问涉及法律问题 | 由法务委员或外聘法律顾问答复 |
| 业主提出反对意见 | 允许充分表达，主持人不得压制 |
| 业主提出新方案 | 如时间允许可简要讨论，否则纳入下次议题 |

## 第四章 表决计票阶段

### 4.1 表决票填写

#### 4.1.1 填票规则

| 规则 | 说明 |
|:-----|:-----|
| **独立填写** | 业主独立填写，不得由他人代填（代理人除外） |
| **一笔一划** | 用钢笔或签字笔填写，不得使用铅笔 |
| **明确选项** | 每议题只能选择一个选项（同意/反对/弃权） |
| **签字确认** | 业主（或代理人）在表决票上签字确认 |
| **禁止涂改** | 涂改无效，可换领新票（须交回原票） |

#### 4.1.2 无效票认定

| 情形 | 处理方式 |
|:-----|:---------|
| 未选择任何选项 | 该议题视为弃权 |
| 同时选择多个选项 | 该议题视为弃权 |
| 涂改无法辨认 | 该议题视为弃权 |
| 未签字确认 | 该议题视为弃权 |
| 表决票编号与业主不符 | 整张表决票无效 |
| 伪造、变造表决票 | 整张表决票无效，追究法律责任 |

### 4.2 投票管理

#### 4.2.1 投票流程

| 步骤 | 操作 | 责任人 | 记录要求 |
|:-----|:-----|:-------|:---------|
| 1 | 业主填写完毕，自行折叠表决票 | 业主本人 | — |
| 2 | 业主将表决票投入投票箱 | 业主本人 | — |
| 3 | 工作人员确认投票箱状态正常 | 监票人 | 检查封条完好 |
| 4 | 投票截止，当众宣布停止投票 | 主持人 | 记录截止时间 |
| 5 | 监票人检查投票箱，确认封条完好 | 监票人 | 拍照存档 |
| 6 | 当众加贴封条，签字确认 | 监票人 | 封条编号记录 |

#### 4.2.2 投票箱管理

| 项目 | 要求 |
|:-----|:-----|
| **投票箱数量** | 至少2个（爱丁堡1期、红郡2期各1个，或现场1个+备用1个） |
| **投票箱规格** | 不透明材质，带锁，顶部有狭长投口 |
| **封条管理** | 一次性封条，编号唯一，封条上注明日期、时间、监票人签字 |
| **开箱程序** | 当众开箱，至少2名监票人在场，全程录像 |

## 第六章 专项表决操作

### 6.1 书面征求意见表决

#### 6.1.1 适用情形

| 情形 | 说明 |
|:-----|:-----|
| 业主分散、难以集中 | 业主长期在外地工作或居住 |
| 事项紧急但非重大 | 需要快速决策但不符合应急维修条件 |
| 程序性事项 | 如业委会委员补选、工作规则修订等 |

#### 6.1.2 操作流程

| 步骤 | 内容 | 时限 | 责任人 |
|:-----|:-----|:----:|:-------|
| 1 | 业委会会议决定采用书面征求意见形式 | — | 全体委员 |
| 2 | 编制表决票、议题说明、回邮信封 | 决定后5日 | 宣传委员 |
| 3 | 向街道办事处报备 | 发放前3日 | 主任 |
| 4 | 发放表决票（上门送达或挂号邮寄） | 发放后15日内回收 | 全体委员+物业 |
| 5 | 设置投票箱（固定点+流动点） | 回收期内 | 物业 |
| 6 | 回收表决票，当众开箱计票 | 回收截止后3日内 | 监票人+计票人 |
| 7 | 公示结果 | 计票后3日内 | 宣传委员 |

#### 6.1.3 发放与回收

| 方式 | 要求 | 记录 |
|:-----|:-----|:-----|
| **上门送达** | 2名以上工作人员共同送达，业主签收 | 签收单存档 |
| **挂号邮寄** | 以业主预留地址为准，保留邮寄回执 | 回执存档 |
| **定点投放** | 在物业服务中心、会所设置投票箱 | 每日清点记录 |
| **流动回收** | 工作人员定时到各楼栋回收 | 回收记录签字 |

### 6.2 电子投票（主要方式）

#### 6.2.1 系统选择

优先使用经政府认证的电子投票平台：

| 平台 | 特点 | 适用场景 |
|:-----|:-----|:---------|
| **粤省事** | 实名认证、微信入口、政府背书、数据可查 | 首选平台 |
| **各地住建部门官方平台** | 房产数据对接、官方认可 | 当地有此类平台时优先 |
| **业主大会专用系统** | 功能完善、符合法规 | 作为备选 |

> **重要提示：** 电子投票全程留痕、不可篡改，比传统纸质投票更透明、更高效。本小区优先采用粤省事进行业主大会投票。

#### 6.2.2 操作流程

| 步骤 | 内容 | 责任人 | 时限 |
|:-----|:-----|:-------|:----:|
| 1 | 业委会会议决定采用电子投票，确定议题 | 全体委员 | 会前25日 |
| 2 | 向街道办事处报备电子投票方案 | 主任 | 会前20日 |
| 3 | 联系电子投票平台（粤省事），提交业主房产数据 | 系统管理员 | 会前15日 |
| 4 | 发布电子投票通知，发送操作指南 | 宣传委员 | 会前15日 |
| 5 | 解答业主咨询，帮助业主完成认证 | 全体委员 | 投票期间 |
| 6 | 跟进投票进度，发送提醒通知 | 宣传委员 | 投票期间 |
| 7 | 投票截止后，从平台导出投票结果 | 系统管理员 | 投票截止后1日内 |
| 8 | 核对结果，公示投票报告 | 业委会 | 导出后3日内 |

#### 6.2.3 操作要点

| 要点 | 要求 |
|:-----|:-----|
| **业主数据导入** | 提前将业主姓名、房号、身份证号、联系方式导入平台 |
| **身份认证** | 确保每位业主已完成平台实名认证，与房产信息绑定 |
| **测试投票** | 正式投票前进行测试投票，验证系统稳定性 |
| **操作指引** | 提供图文或视频操作指南，在微信群传播 |
| **专人答疑** | 投票期间安排人员实时回复咨询 |
| **进度跟踪** | 定期导出投票进度（参与人数、参与率），发送提醒 |
| **结果确认** | 投票结束后，从平台导出带时间戳的投票报告 |

#### 6.2.4 纸质投票备选

对于无法使用电子投票的业主（老年人、无智能手机等），可申请纸质投票作为补充：

| 项目 | 要求 |
|:-----|:-----|
| **申请条件** | 业主本人提出申请，说明原因 |
| **申请时限** | 投票开始前5日提出 |
| **核验方式** | 业委会上门核验业主身份 |
| **投票方式** | 业委会代为在电子平台投票（需业主书面授权） |
| **记录留存** | 纸质申请、授权书、投票截图存档 |

> **特别提示：** GitHub Pages 为静态网站，仅用于公示投票结果。实际投票通过粤省事等政府认证平台进行。

## 第七章 应急情形处理

### 7.1 电子投票系统异常

| 情形 | 处理方式 |
|:-----|:---------|
| **系统宕机** | 启用备用平台或延长投票时间12-24小时 |
| **业主无法登录** | 引导业主找回账号，或申请纸质投票作为替代 |
| **数据丢失** | 联系平台技术方恢复，平台方有义务保障数据完整性 |
| **投票期间异常** | 截图留存，联系平台客服，保留业主投票证据 |

### 7.2 表决争议处理

| 情形 | 处理方式 |
|:-----|:---------|
| **表决票数量不符** | 重新清点，查找原因；如无法查明，以实际清点为准并记录 |
| **表决票真伪争议** | 由监票人鉴定，必要时申请笔迹鉴定 |
| **计票结果争议** | 当场重新计票，由不同计票人复核 |
| **业主现场抗议** | 主持人维持秩序，记录抗议内容，不影响正常计票 |
| **暴力干扰会议** | 立即报警，保护现场，保留证据 |

### 7.3 疫情等不可抗力

| 情形 | 处理方式 |
|:-----|:---------|
| **疫情管控** | 延期召开，或改为书面征求意见形式 |
| **自然灾害** | 延期召开，待灾情解除后重新召集 |
| **政府禁令** | 遵守政府规定，延期或改为线上形式（如允许） |
