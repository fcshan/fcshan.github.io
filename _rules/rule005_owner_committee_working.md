# 翡翠山城别墅区业主委员会工作规则(模板，非正式)

## 第一章 总则

### 第一条 【制定目的】

为规范翡翠山城别墅区业主委员会（以下简称"业委会"）的工作，明确业委会的组织架构、职责分工、议事程序、财务管理、档案管理等事项，保障业委会依法、规范、高效履职，根据《中华人民共和国民法典》《物业管理条例》《业主大会议事规则》《业主管理规约》及相关法律法规，制定本规则。

### 第二条 【适用范围】

本规则适用于业委会全体成员，包括主任、副主任、委员及候补委员。

### 第三条 【工作原则】

业委会工作应当遵循以下原则：

1. **依法依规原则：** 严格遵守法律法规和业主大会授权范围；
2. **集体决策原则：** 重大事项须经业委会会议集体讨论决定，禁止个人擅自决策；
3. **公开透明原则：** 工作内容、财务收支、会议记录向全体业主公开；
4. **勤勉尽责原则：** 委员应当投入必要时间和精力，认真履行职责；
5. **回避利益冲突原则：** 涉及委员个人利益的，该委员应当回避。

## 第二章 组织架构

### 第四条 【业委会组成】

| 职务 | 人数 | 产生方式 | 任期 |
|:-----|:----:|:---------|:----:|
| **主任** | 1人 | 业委会会议选举产生 | 3年 |
| **副主任** | 1人 | 业委会会议选举产生 | 3年 |
| **委员** | 5人 | 业主大会选举产生 | 3年 |
| **候补委员** | 3人 | 业主大会选举产生 | 3年 |
| **合计** | **10人** | — | — |

> **区域平衡：** 爱丁堡1期3名委员、红郡2期3名委员、机动1名委员；候补委员按得票顺序递补。

### 第五条 【职责分工】

#### 5.1 主任职责

| 序号 | 职责内容 |
|:----:|:---------|
| 1 | 召集和主持业委会会议 |
| 2 | 代表业委会对外签署合同、文件 |
| 3 | 审核业委会财务支出（与副主任双签） |
| 4 | 协调业委会与物业服务企业、街道办事处、社区居委会的关系 |
| 5 | 向业主大会报告业委会工作 |
| 6 | 处理业委会日常事务中的紧急事项 |

#### 5.2 副主任职责

| 序号 | 职责内容 |
|:----:|:---------|
| 1 | 协助主任开展工作，主任缺席时代行主任职责 |
| 2 | 审核业委会财务支出（与主任双签） |
| 3 | 分管财务监督、审计对接工作 |
| 4 | 负责业委会档案管理监督 |
| 5 | 协调处理业主重大投诉 |

#### 5.3 委员分工

| 分工领域 | 职责 | 建议人选区域 |
|:---------|:-----|:-------------|
| **工程委员** | 公共设施维护、维修工程管理、招投标监督 | 爱丁堡1期 |
| **财务委员** | 公共收益管理、维修资金管理、预算编制 | 红郡2期 |
| **法务委员** | 合同审查、法律咨询、纠纷调解、规约解释 | 机动/交叉 |
| **宣传委员** | 信息公开、公示网站维护、业主沟通 | 爱丁堡1期 |
| **监督委员** | 物业服务质量监督、业主投诉处理、满意度调查 | 红郡2期 |

> **分工调整：** 委员分工由业委会会议决定，每年可根据实际情况调整一次。

### 第六条 【候补委员】

#### 6.1 递补规则

| 情形 | 递补方式 | 时限 |
|:-----|:---------|:----:|
| 委员辞职 | 得票最多的候补委员自动递补 | 3日内 |
| 委员被罢免 | 得票最多的候补委员自动递补 | 3日内 |
| 委员丧失资格 | 得票最多的候补委员自动递补 | 3日内 |

#### 6.2 候补委员权利

候补委员享有以下权利：

1. 列席业委会会议（无表决权）；
2. 参与业委会组织的调研、检查活动；
3. 接受业委会工作培训；
4. 递补为正式委员后享有完整权利。

## 第三章 会议制度

### 第七条 【会议类型】

| 会议类型 | 召开条件 | 召集人 | 通知期限 | 记录要求 |
|:---------|:---------|:-------|:---------|:---------|
| **定期会议** | 每月至少1次 | 主任 | 3日前 | 专人记录，参会委员签字 |
| **临时会议** | 1/3以上委员提议或主任认为必要时 | 主任 | 1日前 | 专人记录，参会委员签字 |
| **扩大会议** | 涉及专项议题需物业、专家列席时 | 主任 | 3日前 | 专人记录，列席人员签字 |

### 第八条 【会议程序】

#### 8.1 会前准备

| 步骤 | 内容 | 责任人 |
|:-----|:-----|:-------|
| 1 | 确定会议议题，编制议程 | 主任 |
| 2 | 准备会议材料（背景资料、数据、方案） | 相关委员 |
| 3 | 通知全体委员，确认出席情况 | 宣传委员 |
| 4 | 通知列席人员（物业、社区、专家等） | 主任 |
| 5 | 布置会场，准备签到表、表决票 | 宣传委员 |

#### 8.2 会议召开

| 环节 | 要求 |
|:-----|:-----|
| **签到** | 委员本人签到，不得代签；记录出席、缺席、请假情况 |
| **宣布议程** | 主任宣布会议议题，委员可提议增加临时议题（须经半数以上出席委员同意） |
| **议题讨论** | 相关委员汇报，全体讨论，充分发表意见 |
| **表决** | 一人一票，举手表决或记名投票；涉及委员利益的，该委员回避 |
| **形成决议** | 当场宣布表决结果，形成书面决议 |
| **委员签字** | 出席委员在会议记录和决议上签字确认 |

#### 8.3 会议记录

会议记录应当包括以下内容：

| 项目 | 要求 |
|:-----|:-----|
| **基本信息** | 会议时间、地点、议题、召集人、记录人 |
| **出席情况** | 出席委员名单、缺席委员名单及原因、列席人员名单 |
| **发言要点** | 每位委员发言的主要观点（摘要记录，不记原话） |
| **表决情况** | 各议题的表决结果（同意/反对/弃权票数） |
| **决议内容** | 形成的决议事项、执行责任人、完成时限 |
| **签字确认** | 出席委员当场签字，拒绝签字的注明原因 |

> **记录管理：** 会议记录由宣传委员保管，每次会议结束后3日内整理完毕，7日内上传至公示网站。

### 第九条 【决议效力】

#### 9.1 有效条件

| 条件 | 要求 |
|:-----|:-----|
| **出席人数** | 过半数委员出席（即至少4人） |
| **表决通过** | 出席委员过半数同意（即至少3票同意） |
| **回避合规** | 涉及利益冲突的委员已回避 |

#### 9.2 决议类型

| 类型 | 适用情形 | 执行要求 |
|:-----|:---------|:---------|
| **普通决议** | 一般性事务 | 由相关委员执行，主任监督 |
| **重要决议** | 涉及金额>5,000元或影响范围>1栋楼 | 形成书面文件，向业主公示 |
| **紧急决议** | 危及安全的紧急情况 | 可先执行，3日内向业主大会报告 |

## 第四章 财务管理

### 第十条 【财务制度】

业委会应当建立健全财务管理制度，实行**收支两条线、专户存储、双签审批、定期审计**。

### 第十一条 【账户管理】

#### 11.1 账户设置

| 账户类型 | 开户银行 | 用途 | 管理要求 |
|:---------|:---------|:-----|:---------|
| **公共收益基本账户** | XX银行XX支行 | 日常收支 | 主任+副主任双签 |
| **维修资金补充账户** | XX银行XX支行 | 维修资金补充款 | 主任+副主任双签+监理审核 |
| **定期存款账户** | XX银行XX支行 | 闲置资金增值 | 到期自动转存，提前支取须业委会决议 |

#### 11.2 印鉴管理

| 印鉴 | 保管人 | 使用要求 |
|:-----|:-------|:---------|
| **业委会公章** | 宣传委员 | 须经主任或副主任批准，登记使用记录 |
| **财务专用章** | 财务委员 | 须经主任+副主任双签 |
| **主任名章** | 主任本人 | 不得外借 |
| **副主任名章** | 副主任本人 | 不得外借 |

### 第十二条 【收支管理】

#### 12.1 收入管理

| 收入来源 | 收取方式 | 入账时限 | 责任人 |
|:---------|:---------|:---------|:-------|
| 公共停车位收入 | 物业代收，按月划转 | 收到后5日内 | 财务委员核对 |
| 广告收入 | 合同约定的付款方式 | 收到后3日内 | 财务委员核对 |
| 场地租赁收入 | 合同约定的付款方式 | 收到后3日内 | 财务委员核对 |
| 违约金、赔偿金 | 物业或业委会收取 | 收到后3日内 | 财务委员核对 |

#### 12.2 支出审批

| 支出金额 | 审批程序 | 支付方式 |
|:---------|:---------|:---------|
| ≤1,000元 | 主任审批 | 现金或转账 |
| 1,000-5,000元 | 主任+副主任双签 | 转账 |
| 5,000-50,000元 | 业委会会议决议 | 转账 |
| >50,000元 | 业主大会表决 | 转账 |
| 应急支出 | 主任决定，事后业委会追认 | 转账 |

#### 12.3 支出禁止

| 序号 | 禁止行为 | 违规后果 |
|:----:|:---------|:---------|
| 1 | 将业委会资金存入个人账户 | 立即纠正，追究责任 |
| 2 | 未经审批擅自支出 | 由责任人承担，造成损失赔偿 |
| 3 | 挪用资金用于与小区无关的事项 | 立即纠正，追究法律责任 |
| 4 | 白条入账、虚假报销 | 拒绝报销，追究责任 |
| 5 | 向委员发放工资、津贴（法定补贴除外） | 拒绝支付，追究责任 |

### 第十三条 【财务公开】

#### 13.1 公开内容

| 公开事项 | 公开时限 | 公开方式 |
|:---------|:---------|:---------|
| 月度收支明细 | 次月10日前 | 公示网站 |
| 季度财务报表 | 季度结束后15日内 | 公示网站+公告栏 |
| 年度财务预算 | 每年1月底前 | 公示网站+业主大会 |
| 年度财务决算 | 每年12月底前 | 公示网站+业主大会 |
| 重大支出（>50,000元） | 支出后7日内 | 公示网站+公告栏 |

#### 13.2 财务审计

| 审计类型 | 频次 | 审计机构 | 结果处理 |
|:---------|:----:|:---------|:---------|
| **年度审计** | 每年1次 | 第三方会计师事务所 | 审计报告向业主大会报告并公示 |
| **换届审计** | 每届任期届满前 | 第三方会计师事务所 | 审计报告作为交接依据 |
| **专项审计** | 必要时 | 第三方会计师事务所 | 依业主大会或街道办事处要求 |

## 第五章 档案管理

### 第十四条 【档案分类】

| 类别 | 具体内容 | 保管期限 | 保管责任人 |
|:-----|:---------|:--------:|:-----------|
| **会议档案** | 会议通知、签到表、会议记录、决议、表决票 | 永久 | 宣传委员 |
| **合同档案** | 物业服务合同、工程合同、广告合同、租赁合同 | 合同期满后5年 | 法务委员 |
| **财务档案** | 会计凭证、账簿、报表、银行对账单、审计报告 | 永久 | 财务委员 |
| **工程档案** | 设计图纸、招投标文件、施工合同、验收报告、质保文件 | 永久 | 工程委员 |
| **业主档案** | 业主名册（脱敏）、联系方式（保密） | 永久 | 宣传委员 |
| **行政档案** | 与政府部门往来文件、备案材料 | 永久 | 主任 |

### 第十五条 【档案管理要求】

| 项目 | 要求 |
|:-----|:-----|
| **保管地点** | 业委会办公室，配备防火、防潮、防虫、防盗设施 |
| **电子档案** | 重要档案扫描备份，存储于加密硬盘及云端（GitHub私有仓库） |
| **查阅制度** | 业主预约查阅，须登记身份信息，不得拍照、复印（法律法规另有规定的除外） |
| **移交制度** | 委员变更时10日内移交；换届选举后30日内完成全部档案移交 |
| **销毁程序** | 超过保管期限的档案，经业委会决议后销毁，留存销毁记录 |

## 第六章 委员行为规范

### 第十六条 【委员义务】

| 义务 | 具体要求 |
|:-----|:---------|
| **参加会议** | 按时出席业委会会议，因故不能出席须提前请假，每年缺席不超过3次 |
| **执行决议** | 坚决执行业主大会和业委会决议，不得擅自改变或拒不执行 |
| **保守秘密** | 不得泄露业主个人信息、业委会内部讨论内容、尚未公开的决定 |
| **廉洁自律** | 不得利用职务之便谋取私利，不得收受物业服务企业、施工单位财物 |
| **接受监督** | 接受业主、业委会、街道办事处的监督，如实答复质询 |
| **学习提升** | 每年至少参加1次物业管理相关法律法规培训 |

### 第十七条 【禁止行为】

| 序号 | 禁止行为 | 违规处理 |
|:----:|:---------|:---------|
| 1 | 未经业委会授权，以业委会名义对外签署合同、承诺 | 个人承担法律责任，业委会追责 |
| 2 | 擅自使用业委会公章 | 立即纠正，造成损失赔偿 |
| 3 | 泄露业主个人信息 | 立即除名，造成后果追究法律责任 |
| 4 | 收受物业服务企业、施工单位回扣、好处费 | 立即除名，追究法律责任 |
| 5 | 在物业招投标、工程发包中弄虚作假 | 立即除名，追究法律责任 |
| 6 | 利用业委会委员身份为个人或亲友谋取不正当利益 | 立即除名，追究法律责任 |
| 7 | 在业主微信群、公开场合发表与业委会决议相悖的言论 | 警告，造成恶劣影响除名 |
| 8 | 连续三次无故缺席业委会会议 | 视为自动辞职 |

### 第十八条 【利益冲突回避】

#### 18.1 回避情形

委员在以下情形中应当回避：

| 情形 | 说明 |
|:-----|:-----|
| **经济利益关联** | 委员本人、配偶、直系亲属与议题涉及的单位有个人经济利益关系 |
| **职务关联** | 委员在议题涉及的单位任职或担任顾问 |
| **业务关联** | 委员经营的单位与议题涉及的单位有业务往来 |
| **亲属关联** | 议题涉及委员本人或直系亲属的专有部分利益 |

#### 18.2 回避程序

| 步骤 | 内容 |
|:-----|:-----|
| 1 | 委员主动声明回避事由 |
| 2 | 主任确认回避必要性 |
| 3 | 该委员退出会议讨论和表决 |
| 4 | 会议记录中注明回避情况 |
| 5 | 回避委员不得私下影响其他委员 |

## 第七章 监督与问责

### 第十九条 【内部监督】

#### 19.1 委员互评

每年年底，业委会组织委员互评，评价内容包括：

| 评价维度 | 权重 | 评价方式 |
|:---------|:----:|:---------|
| 出席会议情况 | 20% | 统计出席率 |
| 履职贡献度 | 30% | 委员互评打分 |
| 廉洁自律情况 | 30% | 委员互评打分 |
| 业主满意度 | 20% | 抽样调查 |

#### 19.2 主任述职

业委会主任每年向业主大会述职，内容包括：

1. 年度工作总结；
2. 财务收支情况；
3. 重大事项决策回顾；
4. 下年度工作计划；
5. 接受业主质询。

### 第二十条 【外部监督】

| 监督主体 | 监督方式 | 配合要求 |
|:---------|:---------|:---------|
| **全体业主** | 质询、建议、罢免 | 10日内书面答复质询 |
| **街道办事处** | 行政指导、检查、责令改正 | 如实提供材料，配合检查 |
| **社区居委会** | 列席会议、协调指导 | 通知列席重要会议 |
| **区住房和建设局** | 业务监督、行政处罚 | 如实提供材料，配合调查 |
| **审计机构** | 财务审计 | 提供完整财务资料 |

### 第二十一条 【问责程序】

#### 21.1 问责情形

委员有下列情形之一的，应当启动问责程序：

| 情形 | 问责方式 |
|:-----|:---------|
| 轻微违规（如迟到、未按时完成任务） | 口头警告、书面检讨 |
| 一般违规（如泄露内部信息、不当言论） | 通报批评、暂停委员权利1-3个月 |
| 严重违规（如收受回扣、挪用资金） | 提议罢免、追究法律责任 |

#### 21.2 问责程序

```
┌─────────────┐
│  发现违规线索  │
│  （业主举报/内部发现）│
└──────┬──────┘
       │
       ▼
┌─────────────┐
│  主任组织调查  │
│  （7个工作日内）│
└──────┬──────┘
       │
       ▼
┌─────────────┐
│  业委会会议审议│
│  （被问责委员回避）│
└──────┬──────┘
       │
       ▼
┌─────────────┐
│  作出问责决定  │
│  （书面通知被问责委员）│
└──────┬──────┘
       │
       ▼
┌─────────────┐
│  公示问责结果  │
│  （公示网站+公告栏）│
└─────────────┘
```

## 第八章 交接制度

### 第二十二条 【日常交接】

委员因辞职、罢免、丧失资格等原因退出业委会的，应当在退出后10日内完成以下交接：

| 交接事项 | 内容 | 接收人 |
|:---------|:-----|:-------|
| **工作资料** | 分管领域的文件、合同、记录 | 继任委员或主任指定人员 |
| **财务物品** | 经手的现金、票据、报销凭证 | 财务委员 |
| **档案钥匙** | 档案柜、办公室钥匙 | 宣传委员 |
| **电子账号** | 工作邮箱、网站后台、微信群管理权限 | 宣传委员 |
| **未完成事项** | 正在处理的工作及后续安排 | 继任委员 |

### 第二十三条 【换届交接】

新一届业委会产生后，应当在30日内完成以下交接：

| 交接事项 | 内容 | 监督人 |
|:---------|:-----|:-------|
| **公章印鉴** | 业委会公章、财务专用章、名章 | 街道办事处 |
| **财务账目** | 全部银行账户、余额、未了事项 | 审计机构+街道办事处 |
| **档案资料** | 全部纸质档案、电子档案 | 街道办事处 |
| **办公场所** | 办公室、档案柜、办公设备 | 街道办事处 |
| **合同权利义务** | 正在履行的合同清单及履行情况 | 街道办事处 |
| **工作移交清单** | 逐项核对，双方签字确认 | 街道办事处 |

> **审计前置：** 换届交接前，应当委托第三方审计机构对上一届业委会财务进行审计，审计报告作为交接依据。
