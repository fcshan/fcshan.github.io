## 第一章 总则

### 第一条 【制定目的】

为维护翡翠山城别墅区（含爱丁堡1期、红郡2期）全体业主在物业管理活动中的合法权益，规范物业的使用、维护和管理行为，营造安全、舒适、文明、和谐的居住环境，根据《中华人民共和国民法典》《物业管理条例》《广东省物业管理条例》《惠州市物业管理条例》及相关法律法规，结合本小区实际情况，制定本规约。

### 第二条 【适用范围】

本规约适用于翡翠山城别墅区物业管理区域内物业的使用、维护、管理，业主的共同利益，业主应当履行的义务，以及违反规约应当承担的责任。

本规约对物业管理区域内的全体业主、物业使用人（包括但不限于承租人、借用人、访客）均具有约束力。

### 第三条 【物业基本情况】

| 项目 | 内容 |
|:-----|:-----|
| **物业名称** | 翡翠山城别墅区 |
| **物业地址** | 广东省惠州市惠阳区XX路XX号 |
| **占地面积** | 约XX平方米 |
| **总建筑面积** | 94,560.00平方米 |
| **业主户数** | 709户 (爱丁堡1期?户，红郡2期?户) |
| **物业类型** | 别墅住宅区 |
| **交付时间** | 爱丁堡1期：2008年X月；红郡2期：2010年X月 |
| **物业服务企业** | XX物业管理有限公司 |

### 第四条 【管理原则】

      1. 依法管理原则 遵守国家法律法规，尊重社会公德；
      2. 业主自治原则 业主通过业主大会和业主委员会实行自我管理；
      3. 公共利益优先原则 个人利益服从公共利益，局部利益服从整体利益；
      4. 有偿服务原则 业主应当按照约定缴纳物业服务费用和分摊公共费用；
      5. 权限责一致原则 业主享有权利的同时应当履行相应义务。

## 第二章 物业的使用

### 第五条 【专有部分使用】

#### 5.1 一般规定

业主对建筑物专有部分享有占有、使用、收益和处分的权利，但不得危及建筑物的安全，不得损害其他业主的合法权益。

#### 5.2 禁止行为

业主、物业使用人在使用专有部分时，不得有下列行为：

| 序号 | 禁止行为 | 法律依据 | 违规后果 |
|:----:|:---------|:---------|:---------|
| 1 | 擅自改变房屋规划用途（如将住宅改为经营性场所、群租房） | 《民法典》第279条 | 限期改正，恢复原状 |
| 2 | 损坏房屋承重结构、主体结构 | 《建设工程质量管理条例》 | 承担修复费用，造成损失赔偿 |
| 3 | 在专有部分内从事违法活动（如赌博、吸毒、传销） | 《治安管理处罚法》 | 报告公安机关 |
| 4 | 存放易燃、易爆、剧毒、放射性等危险物品 | 《消防法》 | 立即清除，报告消防部门 |
| 5 | 排放超过规定标准的噪声、振动、废气、废水 | 《环境噪声污染防治法》 | 限期整改，赔偿损失 |
| 6 | 从建筑物中抛掷物品 | 《民法典》第1254条 | 承担侵权责任 |

### 第六条 【共有部分使用】

#### 6.1 共有部分范围

本小区共有部分包括但不限于：

| 类别 | 具体内容 |
|:-----|:---------|
| **建筑共有部分** | 建筑物的基础、承重结构、外墙、屋顶、楼梯间、走廊、电梯、门禁系统 |
| **场地共有部分** | 小区道路、绿地、广场、停车场、游泳池、儿童游乐设施、健身设施 |
| **设备共有部分** | 供水、排水、供电、供气、消防、安防、通信、照明设施设备 |
| **空间共有部分** | 架空层、地下室、设备间、管道井、屋顶平台 |

#### 6.2 使用规则

| 使用方式 | 规则 | 审批程序 |
|:---------|:-----|:---------|
| **正常通行** | 遵守交通规则，限速15km/h，禁止鸣笛 | 无需审批 |
| **临时停车** | 服从物业引导，禁止占用消防通道、他人车位 | 无需审批 |
| **绿化区域活动** | 爱护花草树木，禁止践踏、采摘、挖掘 | 无需审批 |
| **公共设施使用** | 遵守使用说明，禁止恶意损坏 | 无需审批 |
| **共有部分临时占用** | 不得妨碍其他业主正常使用 | 须经业委会书面同意 |
| **共有部分经营活动** | 须经业主大会双3/4同意 | 业主大会表决 |

#### 6.3 禁止占用

禁止任何单位和个人擅自占用、挖掘物业管理区域内的道路、场地、绿地、共有空间。因维修物业或者公共利益确需临时占用的，应当征得业主委员会和物业服务企业同意，并在约定期限内恢复原状。

### 第七条 【装饰装修管理】

#### 7.1 装修申报

业主或者物业使用人在装饰装修工程开工前，应当事先告知物业服务企业，并提交以下材料：

| 材料 | 要求 |
|:-----|:-----|
| 房屋产权证明或购房合同 | 复印件 |
| 装饰装修方案 | 包括设计图纸、施工方案、材料清单 |
| 施工单位资质证明 | 营业执照、资质证书复印件 |
| 装修承诺书 | 承诺遵守本规约和装修管理规定 |

#### 7.2 装修禁止行为

| 序号 | 禁止行为 | 违规处理 |
|:----:|:---------|:---------|
| 1 | 拆改承重墙、梁、柱、楼板 | 立即停工，限期恢复原状 |
| 2 | 扩大承重墙上原有门窗尺寸 | 立即停工，限期恢复原状 |
| 3 | 拆除连接阳台的砖、混凝土墙体 | 立即停工，限期恢复原状 |
| 4 | 将没有防水要求的房间改为卫生间、厨房 | 立即停工，限期恢复原状 |
| 5 | 损坏房屋原有节能设施 | 限期修复 |
| 6 | 在非承重外墙上开门、窗 | 须经业委会审核同意 |
| 7 | 改变房屋外立面颜色、材质 | 须经业委会审核同意 |
| 8 | 占用公共空间堆放装修材料 | 限期清理 |
| 9 | 装修施工时间：工作日12:00-14:00、18:00-次日8:00，节假日全天 | 违反一次警告，两次以上罚款500元/次 |

#### 7.3 装修保证金

业主装饰装修前应当向物业服务企业缴纳装修保证金，标准为：

| 项目 | 金额 | 退还条件 |
|:-----|:-----|:---------|
| 装修保证金 | 3,000元/户 | 装修完毕，经物业验收无违规后30日内退还 |
| 装修垃圾清运费 | 按实际产生量计算，约500-1,000元/户 | 不可退还 |

### 第八条 【车辆管理】

#### 8.1 车辆分类

| 类别 | 定义 | 管理要求 |
|:-----|:-----|:---------|
| **业主车辆** | 登记在业主名下或业主直系亲属名下的车辆 | 不干扰他人正常使用 |
| **租户车辆** | 租户使用的车辆 | 办理临时月卡 |
| **访客车辆** | 来访亲友车辆 | 登记后限时免费停放 |
| **临时车辆** | 快递、外卖、维修等服务车辆 | 即停即走，禁止过夜 |

#### 8.2 停车规则

| 规则 | 内容 |
|:-----|:-----|
| **限速** | 小区内行驶限速15km/h，地下车库限速5km/h |
| **禁鸣** | 小区内禁止鸣笛 |
| **禁停区域** | 消防通道、绿化带、人行道、他人固定车位、路口转角 |
| **车位使用** | 固定车位仅限登记车辆停放，不得擅自占用他人车位 |
| **过夜管理** | 临时车辆、访客车辆原则上不得在小区内过夜停放 |
| **电动车/摩托车** | 应当在指定区域停放，禁止进入楼栋内、电梯内 |

#### 8.3 车位分配

| 车位类型 | 数量 | 分配原则 |
|:---------|:----:|:---------|
| **固定产权车位** | XX个 | 以产权登记为准 |
| **公共停车位（地面）** | 80个 | 公共停车位（地面）按申请顺序分配，先到先得 |
| **公共停车位（地下）** | 30个 | 公共停车位（地下）按申请顺序分配，先到先得 |
| **访客车位** | 20个 | 不固定，限时免费 |

> **争议处理：** 车位分配争议由业委会调解，调解不成的按照《业主大会议事规则》申请召开业主大会表决。

### 第九条 【宠物管理】

#### 9.1 养犬规定

| 项目 | 要求 |
|:-----|:-----|
| **登记备案** | 养犬业主应当向物业登记犬只品种、年龄、免疫情况 |
| **免疫要求** | 犬只应当定期注射狂犬疫苗，佩戴免疫标识 |
| **外出约束** | 外出应当由成年人牵引，牵引绳长度不超过2米 |
| **禁入区域** | 儿童游乐区、游泳池、会所餐厅、电梯（高峰时段） |
| **粪便清理** | 犬只排泄物应当即时清理，违者罚款200元/次 |
| **噪声控制** | 犬只吠叫扰民的，业主应当采取措施制止 |
| **禁养犬种** | 禁止饲养烈性犬、大型犬（具体名录依据《惠州市养犬管理条例》） |

#### 9.2 其他宠物

饲养猫、鸟、鱼等其他宠物的，应当遵守以下规定：

      1. 不得影响公共环境卫生；
      2. 不得发出噪声干扰他人正常生活；
      3. 不得在共有部分放养；
      4. 不得饲养法律法规禁止饲养的动物。

## 第三章 物业的维护

### 第十条 【专有部分维护】

#### 10.1 维护责任

业主应当负责专有部分及其附属设施设备的日常维护、养护和管理，保持其安全、整洁、完好。

#### 10.2 渗漏处理

| 渗漏情形 | 责任方 | 处理时限 |
|:---------|:-------|:---------|
| 业主专有部分内部渗漏 | 该业主 | 发现后7日内修复 |
| 楼上业主专有部分渗漏至楼下 | 楼上业主 | 楼下业主通知后3日内到场查看，7日内修复 |
| 共有部分渗漏至专有部分 | 全体业主（维修资金或公共收益） | 物业报修后24小时内响应 |

> **协调机制：** 邻里渗漏纠纷，由物业协调，协调不成的由业委会调解。

### 第十一条 【共有部分维护】

#### 11.1 维护责任划分

| 维护项目 | 责任主体 | 资金来源 |
|:---------|:---------|:---------|
| 房屋承重结构、主体结构 | 全体业主 | 维修资金 |
| 外墙、屋顶防水 | 全体业主 | 维修资金 |
| 电梯、消防设施 | 全体业主 | 维修资金 |
| 道路、路灯、绿化 | 全体业主 | 公共收益或物业费 |
| 门禁、监控、安防系统 | 全体业主 | 公共收益或物业费 |
| 供水、供电、供气主管网 | 全体业主 | 维修资金 |
| 排水管网、化粪池 | 全体业主 | 公共收益或物业费 |

#### 11.2 日常维护

物业服务企业应当按照物业服务合同约定，对共有部分进行日常维护，包括：

| 项目 | 频次 | 标准 |
|:-----|:-----|:-----|
| 公共区域保洁 | 每日 | 道路无垃圾、垃圾桶日产日清 |
| 绿化养护 | 每周 | 草坪修剪、灌木整形、病虫害防治 |
| 电梯维保 | 每15日 | 符合《电梯维护保养规则》要求 |
| 消防设施检查 | 每月 | 灭火器压力正常、消防栓水压达标 |
| 安防系统巡检 | 每周 | 监控画面清晰、门禁系统正常 |
| 路灯照明检查 | 每月 | 亮灯率不低于98% |
| 排水管网疏通 | 每季度 | 雨季前全面检查疏通 |

### 第十二条 【维修资金】

#### 12.1 资金归集

| 项目 | 标准 | 说明 |
|:-----|:-----|:-----|
| **首期维修资金** | 购房时按建筑面积×XX元/㎡缴纳 | 已缴纳完毕 |
| **续筹维修资金** | 余额不足30%时，按建筑面积分摊续筹 | 须经业主大会表决 |
| **公共收益补充** | 每年公共收益的60%划入维修资金 | 自动划转，无需表决 |

#### 12.2 资金使用

| 使用情形 | 金额标准 | 审批程序 |
|:---------|:---------|:---------|
| 日常维修（单项） | ≤5,000元 | 业委会主任审批 |
| 一般维修（单项） | 5,000-50,000元 | 业委会会议表决 |
| 重大维修（单项） | >50,000元或维修资金总额10%以上 | 业主大会表决 |
| 应急维修 | 不限 | 业委会先行决定，事后向业主大会报告 |

#### 12.3 应急维修

发生下列危及房屋安全和人身财产安全的紧急情况，需要立即使用维修资金的，业主委员会可以先行组织维修，事后向业主大会报告：

| 紧急情况 | 示例 |
|:---------|:-----|
| 电梯故障 | 电梯冲顶、蹲底、困人超过30分钟 |
| 消防设施故障 | 消防栓无水、喷淋系统失效、烟感报警器大面积故障 |
| 屋顶、外墙渗漏 | 大面积渗漏导致多户室内受损 |
| 排水设施堵塞 | 化粪池满溢、主排水管破裂 |
| 供电设施故障 | 变压器故障、主电缆短路 |
| 其他紧急情况 | 经业委会认定的其他危及安全的情形 |

> **事后报告：** 应急维修完成后15日内，业委会应当向业主大会报告维修情况，并在公示网站公开维修费用明细。

## 第四章 公共秩序

### 第十三条 【安全管理】

#### 13.1 出入管理

| 人员类别 | 管理要求 |
|:---------|:---------|
| 业主 | 刷卡/人脸识别进出，车辆自动识别 |
| 租户 | 由业主登记备案，发放临时门禁卡 |
| 访客 | 门岗登记，受访业主确认后放行 |
| 快递/外卖 | 门岗登记，限时进出 |
| 施工人员 | 由业主或物业登记，发放临时出入证 |

#### 13.2 安防巡逻

物业服务企业应当建立24小时安防巡逻制度，重点区域包括：

| 时段 | 巡逻频次 | 重点区域 |
|:-----|:---------|:---------|
| 白天（6:00-22:00） | 每2小时1次 | 主要道路、停车场、公共设施 |
| 夜间（22:00-6:00） | 每小时1次 | 围墙周边、地下车库、偏僻角落 |

#### 13.3 监控管理

| 项目 | 要求 |
|:-----|:-----|
| **监控覆盖** | 小区出入口、主干道、停车场、电梯轿厢、门禁区域全覆盖 |
| **录像保存** | 不少于30日 |
| **查阅权限** | 公安机关、业委会（涉及业主共同利益时）、业主本人（涉及个人权益时） |
| **隐私保护** | 监控不得覆盖业主专有部分窗户、庭院 |

### 第十四条 【消防管理】

#### 14.1 业主义务

| 义务 | 要求 |
|:-----|:-----|
| **不占用消防通道** | 禁止在消防通道停放车辆、堆放物品 |
| **不损坏消防设施** | 禁止挪用、损坏灭火器、消防栓、烟感报警器 |
| **不违规用电** | 禁止私拉电线、超负荷用电、电动车室内充电 |
| **配合消防演练** | 每年至少参加1次消防演练 |
| **报告火情** | 发现火情立即拨打119并通知物业 |

#### 14.2 物业责任

物业服务企业应当履行以下消防安全职责：

      1. 建立健全消防安全制度，落实消防安全责任制；
      2. 定期开展消防设施检查、维护和保养；
      3. 每年至少组织1次消防演练；
      4. 开展消防安全宣传教育；
      5. 及时消除火灾隐患，对拒不整改的报消防部门处理。

### 第十五条 【环境卫生】

#### 15.1 垃圾分类

| 类别 | 投放要求 | 收集时间 |
|:-----|:---------|:---------|
| **厨余垃圾** | 沥干后投放至绿色垃圾桶 | 每日19:00-21:00 |
| **可回收物** | 清洁干燥后投放至蓝色垃圾桶 | 每日 |
| **有害垃圾** | 投放至红色垃圾桶 | 每月15日集中收集 |
| **其他垃圾** | 投放至黑色垃圾桶 | 每日 |

#### 15.2 禁止行为

| 序号 | 禁止行为 | 违规处理 |
|:----:|:---------|:---------|
| 1 | 随地吐痰、便溺 | 罚款100元/次 |
| 2 | 乱扔果皮、纸屑、烟蒂 | 罚款50元/次 |
| 3 | 高空抛物 | 罚款500-2,000元/次，造成损失赔偿 |
| 4 | 在共有部分乱涂乱画、张贴广告 | 责令清除，罚款200元/次 |
| 5 | 在共有部分堆放杂物、垃圾 | 限期清理，逾期物业代为清理，费用由业主承担 |
| 6 | 在共有部分焚烧物品、燃放烟花爆竹 | 罚款500元/次，报告消防部门 |
| 7 | 向排水管网倾倒油污、杂物 | 罚款500元/次，造成堵塞承担疏通费用 |

## 第五章 费用分摊

### 第十六条 【物业服务费】

#### 16.1 收费标准

| 物业类型 | 收费标准 | 计费方式 | 包含内容 |
|:---------|:---------|:---------|:---------|
| 别墅住宅 | X.XX元/㎡·月 | 按专有部分建筑面积 | 保洁、绿化、秩序维护、公共设施日常维护 |
| 地下车库（产权车位） | XX元/位·月 | 按车位 | 照明、保洁、安防、设施维护 |

#### 16.2 缴纳方式

| 方式 | 说明 |
|:-----|:-----|
| **银行代扣** | 与银行签订代扣协议，每月自动扣款 |
| **线上支付** | 通过微信、支付宝、物业APP缴纳 |
| **现场缴纳** | 至物业服务中心现金或刷卡缴纳 |

#### 16.3 缴纳期限

业主应当按照物业服务合同约定，于每月XX日前缴纳当月物业服务费。逾期缴纳的，按照以下标准支付违约金：

| 逾期时间 | 违约金标准 |
|:---------|:-----------|
| 1-30日 | 每日按欠费金额的0.3‰ |
| 31-90日 | 每日按欠费金额的0.5‰ |
| 超过90日 | 每日按欠费金额的1‰，业委会可公示欠费名单（脱敏处理） |

> **催缴程序：** 逾期30日，物业书面催缴；逾期60日，物业电话催缴并发送律师函；逾期90日，物业可依法提起诉讼或申请仲裁。

### 第十七条 【公共费用分摊】

#### 17.1 分摊原则

| 费用类型 | 分摊原则 | 说明 |
|:---------|:---------|:-----|
| **共有部分能耗** | 按专有部分建筑面积比例分摊 | 电梯、水泵、路灯、景观照明等 |
| **共有部分水费** | 按专有部分建筑面积比例分摊 | 绿化养护、道路清洗、消防用水等 |
| **公共设施维护费** | 按专有部分建筑面积比例分摊 | 超出物业费范围的维护费用 |
| **业主大会经费** | 按户数均摊 | 会议场地、资料印刷、误工补贴等 |

#### 17.2 分摊程序

      1. 物业服务企业或者业委会编制费用分摊方案；
      2. 方案公示7日，征求业主意见；
      3. 无异议或者异议不成立的，按照方案分摊；
      4. 有异议且涉及金额较大的，提交业主大会表决。

### 第十八条 【公共收益】

#### 18.1 收益范围

| 来源 | 说明 |
|:-----|:-----|
| **公共停车位收入** | 临时停车、访客车位、充电桩服务费分成 |
| **广告收入** | 电梯轿厢广告、灯箱广告、道闸广告 |
| **场地租赁收入** | 快递柜、生鲜柜、便民服务站、通信基站 |
| **其他收入** | 废旧物资处置、利息收入等 |

#### 18.2 收益使用

| 用途 | 比例 | 说明 |
|:-----|:----:|:-----|
| 补充专项维修资金 | 60% | 划入维修资金专户 |
| 公共设施维护更新 | 30% | 用于超出物业费范围的维护 |
| 业主大会经费储备 | 10% | 用于年度业主大会开支 |

#### 18.3 收益公示

公共收益收支情况每季度结束后15日内公示，公示期30日。公示内容包括：

      1. 收入项目、金额、来源；
      2. 支出项目、金额、用途；
      3. 结余金额及资金存放情况；
      4. 业主查询方式。

## 第六章 违约责任

### 第十九条 【业主违约】

#### 19.1 违约情形

业主违反本规约的，应当承担以下责任：

| 违约行为 | 责任形式 | 具体措施 |
|:---------|:---------|:---------|
| 欠缴物业服务费 | 民事责任 | 支付欠费本金、违约金，物业可提起诉讼 |
| 损坏共有部分 | 民事责任 | 恢复原状或赔偿损失 |
| 妨碍他人合法权益 | 民事责任 | 停止侵害、排除妨碍、赔偿损失 |
| 违反装修规定 | 行政+民事责任 | 物业制止、报告行政部门、赔偿损失 |
| 违法搭建 | 行政责任 | 物业制止、报告城管部门、限期拆除 |
| 高空抛物 | 民事+刑事责任 | 赔偿损失，情节严重追究刑事责任 |
| 饲养烈性犬 | 行政责任 | 报告公安机关，依法处理 |

#### 19.2 违约金管理

物业服务企业依据本规约收取的违约金，应当纳入公共收益管理，不得挪作他用。

### 第二十条 【连带责任】

#### 20.1 承租人责任

业主出租房屋的，应当与承租人约定遵守本规约。承租人违反本规约的，业主承担连带责任。

#### 20.2 物业使用人责任

物业使用人（借用人、访客等）违反本规约的，由物业使用人承担责任；物业使用人拒不承担责任的，由业主承担责任。

### 第二十一条 【纠纷处理】

#### 21.1 协商调解

业主之间、业主与物业之间因本规约发生纠纷的，按照以下顺序处理：

```
自行协商 → 物业调解 → 业委会调解 → 社区居委会调解 → 街道办事处调解 → 法院诉讼/仲裁
```

#### 21.2 规约执行

对违反本规约的行为，任何业主、业委会、物业服务企业均有权制止，并向有关行政部门报告。
