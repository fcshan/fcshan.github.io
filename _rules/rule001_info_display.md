## 1. 个人信息保护

严格脱敏原则：

- 公示投票结果时，只展示"同意/反对/弃权"的票数、面积占比，不公示具体房号、业主姓名
- 财务公示中，涉及业主个人缴费、欠费信息一律不上网
- 会议签到表、签到照片如有上传，必须对所有人脸、姓名、房号进行打码处理
- 不要公开任何业主的联系方式、车牌号、家庭成员信息
法律依据：《个人信息保护法》《民法典》第1034条

## 2. 内容发布边界

只发布"组织行为"结果，不发布"个人评价"


## 3.会议纪要规范

- 只记录议题、讨论要点、表决结果、后续安排
- 不记录"某某业主说了什么"（除非该业主明确要求记录并公开其发言）
- 涉及业主投诉内容的，隐去投诉人身份信息，只陈述事项和处理结果


## 4. 信息发布规范

| 类型   | 发布要求                | 留存方式                 |
| :--- | :------------------ | :------------------- |
| 会议通知 | 提前7天发布，附时间、地点、议题    | 同步上传至GitHub Pages公示站 |
| 表决结果 | 附参与率、同意率，不公开具体房号    | 公示站永久存档              |
| 财务通报 | 季度汇总，不公开个人缴费明细      | PDF上传公示站             |
| 紧急通知 | 如紧急情况，可@全员，事后补发正式公告 | 截图存档                 |


## 5. 群规修订与公示

- 本原则由临时业主大会筹备组起草
- 修订须提前7天在群内公示，收集意见后由临时业主大会筹备组审定
- 本原则同步发布于小区GitHub Pages公示站：<https://fcshan.github.io/rules/rule001-info-display/>
