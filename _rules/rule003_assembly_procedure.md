# 翡翠山城别墅区业主大会议事规则(模板，非正式)

**规则编号：** FCSC-RU-001  
**制定日期：** 2026年X月X日  
**生效日期：** 2026年X月X日（经首次业主大会表决通过之日起生效）  
**修订记录：** [见附录E]  
**备案单位：** XX街道办事处 / XX区住房和建设局  

---

## 第一章 总则

### 第一条 【制定目的】

为规范翡翠山城别墅区业主大会的活动，维护全体业主的合法权益，保障物业管理区域内物业管理的正常运行，根据《中华人民共和国民法典》《物业管理条例》《广东省物业管理条例》《惠州市物业管理条例》及相关法律法规，结合本小区实际情况，制定本规则。

### 第二条 【适用范围】

本规则适用于翡翠山城别墅区（含爱丁堡1期、红郡2期）业主大会的组织、召开、表决及业主委员会的选举、履职、监督等活动。

### 第三条 【基本原则】

业主大会活动应当遵循以下原则：

1. **合法合规原则：** 遵守法律法规，不得损害国家利益、社会公共利益和他人合法权益；
2. **民主决策原则：** 重大事项由业主共同决定，保障业主的知情权、参与权、表达权和监督权；
3. **公开透明原则：** 会议召集、议题确定、表决过程、结果公示全程公开；
4. **少数服从多数原则：** 在法定参与比例和表决比例框架内形成有效决议；
5. **权责对等原则：** 业主享有权利的同时应当履行业主义务。

### 第四条 【业主大会性质】

业主大会由物业管理区域内全体业主组成，代表和维护全体业主在物业管理活动中的合法权益，是小区物业管理的最高决策机构。

**业主大会依法决定下列事项：**

| 序号 | 事项 | 法律依据 | 表决要求 |
|:----:|:-----|:---------|:---------|
| 1 | 制定和修改业主大会议事规则 | 《民法典》第278条第1款 | 双2/3参与 + 双过半同意 |
| 2 | 制定和修改管理规约 | 《民法典》第278条第2款 | 双2/3参与 + 双过半同意 |
| 3 | 选举业主委员会或者更换业主委员会成员 | 《民法典》第278条第3款 | 双2/3参与 + 双过半同意 |
| 4 | 选聘和解聘物业服务企业 | 《民法典》第278条第4款 | 双2/3参与 + 双过半同意 |
| 5 | 使用建筑物及其附属设施的维修资金 | 《民法典》第278条第5款 | 双2/3参与 + 双过半同意 |
| 6 | 筹集建筑物及其附属设施的维修资金 | 《民法典》第278条第6款 | 双2/3参与 + 双3/4同意 |
| 7 | 改建、重建建筑物及其附属设施 | 《民法典》第278条第7款 | 双2/3参与 + 双3/4同意 |
| 8 | 改变共有部分的用途或者利用共有部分从事经营活动 | 《民法典》第278条第8款 | 双2/3参与 + 双3/4同意 |
| 9 | 有关共有和共同管理权利的其他重大事项 | 《民法典》第278条第9款 | 双2/3参与 + 双过半同意 |

> **术语说明：**
> - **"双2/3参与"**：指应当由专有部分面积占比三分之二以上的业主且人数占比三分之二以上的业主参与表决；
> - **"双过半同意"**：指应当经参与表决专有部分面积过半数的业主且参与表决人数过半数的业主同意；
> - **"双3/4同意"**：指应当经参与表决专有部分面积四分之三以上的业主且参与表决人数四分之三以上的业主同意。

## 第二章 业主大会会议

### 第五条 【会议类型】

业主大会会议分为**定期会议**和**临时会议**。

| 会议类型 | 召开条件 | 召集人 | 通知期限 |
|:---------|:---------|:-------|:---------|
| **定期会议** | 每年至少召开一次，原则上于每年第一季度召开 | 业主委员会 | 会议召开15日前 |
| **临时会议** | 符合第六条情形之一 | 业主委员会/提议业主/街道办事处 | 会议召开15日前 |

### 第六条 【临时会议召集条件】

有下列情形之一的，应当召开业主大会临时会议：

1. 经专有部分占建筑物总面积20%以上且占总人数20%以上的业主联名书面提议的；
2. 发生重大事故或者紧急事件需要及时处理的；
3. 业主委员会成员人数不足总数的二分之一的；
4. 业主委员会决定召集的；
5. 街道办事处或者区住房和建设局要求召开的；
6. 业主大会议事规则或者管理规约规定的其他情形。

### 第七条 【会议形式】

业主大会会议可以采用以下形式：

| 形式 | 适用情形 | 程序要求 |
|:-----|:---------|:---------|
| **集体讨论** | 重大事项、首次业主大会 | 现场会议，业主签到，当场表决 |
| **书面征求意见** | 一般事项、定期会议 | 发放表决票，回收统计 |
| **电子投票** | 辅助形式，需与书面形式结合 | 须经业主大会表决通过后方可启用 |

> **特别规定：** 首次业主大会应当采用集体讨论形式。筹集维修资金、改建重建建筑物等重大事项，原则上应当采用集体讨论形式或书面征求意见形式，电子投票仅作为辅助手段。

### 第八条 【会议通知】

#### 8.1 通知内容

会议通知应当包括以下内容：

1. 会议召开的时间、地点、形式；
2. 会议议题、议程及具体内容；
3. 表决事项及表决规则；
4. 业主参与方式及所需材料；
5. 会务联系人及联系方式；
6. 其他需要说明的事项。

#### 8.2 通知方式

| 方式 | 要求 | 送达时间 |
|:-----|:-----|:---------|
| 书面张贴 | 在小区主要出入口、公告栏、各楼栋单元门口张贴 | 会议召开15日前 |
| 电子推送 | 业主微信群、短信、电子邮件（以业主预留联系方式为准） | 会议召开15日前 |
| 网站公示 | 在小区GitHub Pages公示站发布 | 会议召开15日前 |
| 上门送达 | 对行动不便的老年业主、长期未参与表决的业主 | 会议召开10日前 |

> **送达确认：** 采用电子方式通知的，应当保留发送记录；采用书面方式通知的，应当拍照存档。通知发出后即视为送达，业主未查看不影响会议效力。

### 第九条 【业主参会资格】

#### 9.1 业主认定

业主是指依法登记取得或者根据《民法典》规定取得建筑物专有部分所有权的人。

| 情形 | 业主身份认定 | 参会方式 |
|:-----|:-------------|:---------|
| 已办理产权登记 | 以不动产登记簿记载的权利人为准 | 本人参会或委托代理人 |
| 尚未办理产权登记（已合法占有） | 以购房合同记载的买受人为准 | 本人参会或委托代理人 |
| 房屋已出售但未过户 | 以不动产登记簿记载的权利人为准 | 原业主参会 |
| 多人共有 | 推选一名代表参会，或全体共有人共同委托一名代理人 | 须提交共有关系证明 |

#### 9.2 代理人

业主可以委托代理人参加业主大会会议，代理人应当具备以下条件：

1. 具有完全民事行为能力；
2. 非本小区物业服务企业工作人员；
3. 同一代理人接受的委托不得超过3户。

**委托书应当载明：**
- 委托人姓名、房号、联系方式；
- 代理人姓名、身份证号、联系方式；
- 委托事项及权限（一般授权/特别授权）；
- 委托期限；
- 委托人签字（盖章）。

> **禁止代理情形：** 筹集维修资金、改建重建建筑物、选聘解聘物业服务企业等重大事项，原则上应当由业主本人表决，确需委托的须经业主委员会审核同意。

### 第十条 【业主投票权】

#### 10.1 投票权计算

| 计算方式 | 说明 | 适用场景 |
|:---------|:-----|:---------|
| **面积票权** | 以业主专有部分建筑面积占小区总建筑面积的比例计算 | 面积相关表决 |
| **人数票权** | 一个专有部分按一人计算 | 人数相关表决 |
| **双重要求** | 面积和人数均需达到法定比例 | 所有业主大会表决事项 |

#### 10.2 特殊情形

| 情形 | 投票权处理 |
|:-----|:-----------|
| 车位、摊位等特定空间 | 不计入用于确定业主投票权数的专有部分面积 |
| 建设单位尚未出售的车位 | 不计入投票权 |
| 同一买受人拥有多个专有部分 | 按一人计算 |
| 房屋空置 | 不影响投票权，业主仍享有表决权 |
| 欠缴物业费 | 不影响投票权，但可能影响业主委员会委员候选人资格 |

## 第三章 业主大会表决

### 第十一条 【表决方式】

#### 11.1 表决票形式

| 形式 | 要求 | 适用情形 |
|:-----|:-----|:---------|
| **纸质表决票** | 统一印制，编号管理，防伪标识 | 所有会议均可使用 |
| **电子表决** | 须经业主大会授权，采用经认证的电子投票系统 | 辅助形式 |
| **举手表决** | 仅适用于非重大事项的程序性决议 | 集体讨论形式 |

#### 11.2 表决意见

表决票应当设置以下选项：

| 选项 | 含义 | 计票规则 |
|:-----|:-----|:---------|
| **同意** | 赞成该表决事项 | 计入同意票 |
| **反对** | 不赞成该表决事项 | 计入反对票 |
| **弃权** | 放弃表决权利 | 计入参与表决人数/面积，但不计入同意或反对 |
| **未参与** | 未在规定时间内提交表决票 | 不计入参与表决基数 |

> **禁止事项：** 表决票不得设置"同意多数意见""随大流"等模糊选项；不得诱导、胁迫业主作出特定选择。

### 第十二条 【表决程序】

#### 12.1 表决流程

```
┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│  发放表决票  │ → │  业主填票    │ → │  回收表决票  │
│  （编号登记）│    │  （独立填写）│    │  （当场密封）│
└─────────────┘    └─────────────┘    └──────┬──────┘
                                              │
┌─────────────┐    ┌─────────────┐    ┌──────▼──────┐
│  结果公示    │ ← │  监票计票    │ ← │  当众开箱    │
│  （7日异议期）│    │  （双重复核）│    │  （全程录像）│
└─────────────┘    └─────────────┘    └─────────────┘
```

#### 12.2 表决票管理

| 环节 | 管理要求 |
|:-----|:---------|
| **发放** | 核对业主身份，登记表决票编号，业主签字领取 |
| **填写** | 业主独立填写，不得由他人代填（代理人除外） |
| **回收** | 设置投票箱，由监票人当场加贴封条 |
| **保管** | 投票期间由监票人保管钥匙，任何人不得单独接触 |
| **开箱** | 会议结束后当众开箱，全程录像，业主可现场监督 |

### 第十三条 【表决结果统计】

#### 13.1 统计规则

| 项目 | 计算方式 |
|:-----|:---------|
| **参与率（面积）** | 参与表决业主专有部分面积之和 ÷ 小区专有部分总面积 |
| **参与率（人数）** | 参与表决业主人数 ÷ 小区业主总人数 |
| **同意率（面积）** | 同意业主专有部分面积之和 ÷ 参与表决业主专有部分面积之和 |
| **同意率（人数）** | 同意业主人数 ÷ 参与表决业主人数 |

#### 13.2 有效性判定

| 判定标准 | 要求 |
|:---------|:-----|
| **会议有效** | 面积参与率 ≥ 2/3 且 人数参与率 ≥ 2/3 |
| **决议通过（一般事项）** | 会议有效，且面积同意率 > 1/2 且 人数同意率 > 1/2 |
| **决议通过（重大事项）** | 会议有效，且面积同意率 ≥ 3/4 且 人数同意率 ≥ 3/4 |
| **决议不通过** | 未达到上述比例 |

> **弃权处理：** 弃权票计入参与表决基数，但不计入同意或反对。如同意票和反对票均未过半，该事项视为未通过。

### 第十四条 【表决结果公示】

#### 14.1 公示内容

表决结果应当包括：

| 内容 | 要求 |
|:-----|:-----|
| 会议基本情况 | 召开时间、地点、形式、议题 |
| 参与情况 | 应参与户数/面积、实际参与户数/面积、参与率 |
| 表决结果 | 同意户数/面积及比例、反对户数/面积及比例、弃权户数/面积及比例 |
| 决议效力 | 是否达到法定比例、决议是否通过 |
| 异议渠道 | 公示期限、异议提交方式、处理程序 |

#### 14.2 公示要求

| 项目 | 要求 |
|:-----|:-----|
| **公示期限** | 不少于7日 |
| **公示方式** | 小区公告栏、业主微信群、GitHub Pages公示站 |
| **数据脱敏** | 公示统计结果，不公开具体房号、业主姓名 |
| **异议处理** | 公示期内接受书面异议，10个工作日内答复 |

## 第四章 业主委员会

### 第十五条 【业委会组成】

#### 15.1 委员名额

| 项目 | 设置 |
|:-----|:-----|
| **委员人数** | 5-11人（单数），本小区暂定为7人 |
| **候补委员** | 2-3人，按得票多少排序 |
| **任期** | 每届任期3-5年，本小区暂定为3年 |
| **连任限制** | 委员可以连选连任，但同一职务连任不得超过两届 |

#### 15.2 区域平衡

| 区域 | 委员名额 | 候补名额 | 说明 |
|:-----|:--------:|:--------:|:-----|
| 爱丁堡1期 | 3人 | 1人 | 按专有部分面积比例分配 |
| 红郡2期 | 3人 | 1人 | 按专有部分面积比例分配 |
| **机动/交叉** | 1人 | 1人 | 兼顾两区域利益的业主 |
| **合计** | **7人** | **3人** | — |

### 第十六条 【业委会委员条件】

#### 16.1 积极条件

业主委员会委员候选人应当符合以下条件：

1. 具有完全民事行为能力；
2. 为本小区业主（以不动产登记簿或购房合同为准）；
3. 遵守国家法律法规和本小区管理规约；
4. 热心公益事业，责任心强，公正廉洁；
5. 具有一定的组织能力和必要的工作时间；
6. 未处于失信被执行人名单；
7. 本人及其近亲属未在本小区物业服务企业任职。

#### 16.2 消极条件（不得担任情形）

有下列情形之一的，不得担任业主委员会委员：

| 序号 | 情形 | 说明 |
|:----:|:-----|:-----|
| 1 | 违反管理规约，欠缴物业费超过6个月 | 以物业服务企业书面催缴记录为准 |
| 2 | 违反房屋使用规定，擅自改变房屋用途 | 如将住宅改为群租房、经营性场所 |
| 3 | 损坏房屋承重结构、违法搭建 | 以行政部门认定为准 |
| 4 | 被依法追究刑事责任 | 刑罚执行完毕之日起5年内 |
| 5 | 被业主委员会罢免未满3年 | — |
| 6 | 其他不适宜担任的情形 | 由业主大会认定 |

### 第十七条 【业委会职责】

业主委员会履行以下职责：

| 类别 | 具体职责 |
|:-----|:---------|
| **召集会议** | 召集业主大会会议，报告物业管理实施情况 |
| **签订合同** | 代表业主与物业服务企业签订、变更或解除物业服务合同 |
| **监督物业** | 监督物业服务企业履行合同，考核服务质量 |
| **财务管理** | 管理公共收益，定期公布收支情况 |
| **维修资金** | 组织维修资金的筹集、使用和管理 |
| **纠纷调解** | 调解业主之间、业主与物业之间的纠纷 |
| **档案管理** | 保管业主大会和业委会会议记录、合同文本、财务凭证等 |
| **配合执法** | 配合街道办事处、社区居委会、行政部门做好相关工作 |
| **其他职责** | 业主大会赋予的其他职责 |

### 第十八条 【业委会会议】

#### 18.1 会议召开

| 项目 | 要求 |
|:-----|:-----|
| **定期会议** | 每月至少召开一次，原则上于每月第一个周六 |
| **临时会议** | 经三分之一以上委员提议，或主任认为必要时 |
| **通知期限** | 会议召开3日前通知全体委员 |
| **会议记录** | 专人记录，参会委员签字确认，存档备查 |

#### 18.2 议事规则

| 项目 | 要求 |
|:-----|:-----|
| **出席要求** | 过半数委员出席方可召开 |
| **表决方式** | 一人一票，举手表决或记名投票 |
| **通过标准** | 全体委员过半数同意 |
| **回避制度** | 涉及委员本人利益的，该委员应当回避 |
| **会议公开** | 业委会会议应当邀请社区居委会列席，业主可旁听（涉及个人隐私的除外） |

### 第十九条 【业委会委员罢免】

#### 19.1 罢免条件

业主委员会委员有下列情形之一的，经业主大会会议通过，可以罢免其委员资格：

| 序号 | 情形 |
|:----:|:-----|
| 1 | 不履行业主委员会委员职责，连续三次无故缺席业委会会议 |
| 2 | 利用职务之便谋取私利，侵占公共收益或维修资金 |
| 3 | 泄露业主个人信息，造成严重后果 |
| 4 | 被依法追究刑事责任 |
| 5 | 丧失民事行为能力 |
| 6 | 不再具备本小区业主身份 |
| 7 | 其他严重损害业主共同利益的情形 |

#### 19.2 罢免程序

```
┌─────────────────┐
│  20%以上业主联名  │
│  或业委会三分之一 │
│  以上委员提议     │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│  业委会核实情况   │
│  （7个工作日内）  │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│  召开业主大会    │
│  进行罢免表决    │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│  双过半同意      │
│  罢免生效        │
└─────────────────┘
```

> **补选规则：** 委员被罢免或辞职的，由候补委员按得票顺序递补；候补委员不足时，应当在3个月内召开业主大会补选。

## 第六章 监督与争议解决

### 第二十二条 【业主监督】

业主享有以下监督权利：

| 权利 | 行使方式 |
|:-----|:---------|
| **知情权** | 查阅业主大会档案、业委会会议记录、财务凭证（须预约登记） |
| **质询权** | 向业委会书面提出质询，业委会应当在10个工作日内书面答复 |
| **建议权** | 向业委会或业主大会提出合理化建议 |
| **罢免权** | 联名20%以上业主提议罢免业委会委员 |
| **诉讼权** | 对侵害业主共同利益的行为，依法向人民法院提起诉讼 |

### 第二十三条 【行政监督】

| 监督主体 | 监督内容 | 监督方式 |
|:---------|:---------|:---------|
| **街道办事处** | 业主大会召开程序、业委会选举、重大事项表决 | 列席会议、审查备案材料、责令改正 |
| **区住房和建设局** | 物业服务企业资质、维修资金管理、招投标程序 | 行政检查、行政处罚 |
| **社区居委会** | 业委会日常工作、业主纠纷调解 | 列席会议、协调指导 |

### 第二十四条 【争议解决】

#### 24.1 内部协商

业主之间、业主与业委会之间、业主与物业之间的争议，应当首先通过协商解决。

#### 24.2 调解程序

| 步骤 | 方式 | 期限 |
|:-----|:-----|:-----|
| 第一步 | 向业委会申请调解 | 业委会应当在15日内组织调解 |
| 第二步 | 向社区居委会申请调解 | 居委会应当在30日内完成调解 |
| 第三步 | 向街道办事处申请调解 | 街道办应当在60日内完成调解 |

#### 24.3 司法救济

调解不成的，当事人可以依法向人民法院提起诉讼，或者依据合同约定申请仲裁。
