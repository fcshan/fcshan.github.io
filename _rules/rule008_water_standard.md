## 1 范围

本文件规定了二次供水设施的**基本卫生要求、机房卫生要求、水箱(池)卫生要求、消毒设备卫生要求和运营要求**。

本文件适用于**生活饮用水二次供水设施**。

---

## 2 术语和定义

| 术语 | 定义 |
|:-----|:-----|
| **二次供水** | 集中式供水在入户之前经再度储存、加压和消毒，通过管道输送给用户的供水方式 |
| **二次供水设施** | 集中式供水在入户前设置的储存、加压、消毒、输送等设备及管道 |
| **水箱(池)** | 储存生活饮用水的箱或池（包括低位水箱(池)、中位水箱、高位水箱） |
| **无负压给水设备** | 直接串接到市政给水管网，有效利用已有管网压力的给水设备 |
| **运营单位** | 负责二次供水设施运转、经营、维护和管理的单位 |

---

## 3 基本卫生要求

- 二次供水设施应**独立设置在锁闭的机房内**
- 二次供水的供水管道**不应与非饮用水管道及设备直接连接**
- 供水管道的布置与铺设应符合 GB 50015 的规定
- 输配水设备及防护材料应符合 GB/T 17219 的规定
- 消毒剂和消毒设备应符合《生活饮用水消毒剂和消毒设备卫生安全评价规范(试行)》规定
- 二次供水设施的**进水管和出水管应分别设置水样采样口**

---

## 4 机房卫生要求

| 要求 | 内容 |
|:-----|:-----|
| 门禁安全 | 机房门窗应锁闭，窗户应安装防护格栅，宜设置门禁系统、视频监控系统 |
| 防害措施 | 机房应设置挡鼠板及防虫害装置 |
| 设备基础 | 机房内设备基座基础顶面距机房地面不应小于 0.1m |
| 通风排水 | 机房应设有机械通风、排水、防淹报警装置，地面应有不小于 0.01 的坡度坡向排水设施 |
| 环境要求 | 有条件的机房顶部及墙壁可贴瓷砖或涂刷防水防霉涂料 |
| 防冻措施 | 寒冷地区应设置防冻设施 |
| 杂物管理 | 机房内**不应存放杂物** |

## 5 水箱(池)卫生要求

### 5.1 选址与周边

| 要求 | 内容 |
|:-----|:-----|
| 安全距离 | 水箱(池)距污染源、污染物的距离应符合 GB 50015 规定 |
| 环境整洁 | 保持周边环境整洁 |
| 专用性 | 水箱(池)应专用，**不应与非饮用水水箱(池)连接** |
| 设计容积 | 水箱(池)的设计容积**不应超过用户48h的用水量** |

### 5.2 设施要求

| 要求 | 内容 |
|:-----|:-----|
| 通气装置 | 水箱应设置通气管和通气管罩，数量不应少于2个，宜对角安装，并设有耐腐蚀材料滤网和防虫网 |
| 人孔设置 | 水箱(池)应设置人孔，位于水箱顶部，高于水箱顶部 0.05m 以上，人孔应设盖(或门)和锁，**实行双人双锁管理**，并做好开启记录 |
| 顶部间距 | 设置在建筑物内的水箱顶部与屋顶的距离应不小于 0.8m |
| 表面要求 | 水箱(池)与饮用水接触表面应保证外观良好，**光滑平整、不渗漏** |
| 内外部件 | 水箱(池)内、外均应设置爬梯 |

### 5.3 管道设置

| 管道 | 要求 |
|:-----|:-----|
| 进水管 | 应位于水箱(池)上部，溢流边缘的空气间隙不应小于进水管管径，且不应小于 25mm，可不大于 150mm |
| 出水管 | 应位于水箱(池)下部 |
| 进出管位置 | 进水管与出水管应设置在水箱对侧 |
| 溢流管 | 管径应大于进水管管径，与排水系统**不应直接连接**，空气间隙不少于 0.2m |
| 泄水管 | 设在水箱底部，与排水系统**不应直接连接**，空气间隙不少于 0.2m |
| 防护网 | 溢流管和泄水管出口均应设置耐腐蚀材料滤网和防虫网 |

### 5.4 监控设施

- 水箱(池)应设置**水位监控、溢流报警装置**
- 有条件的可设置水质在线监测系统

## 6 消毒设备卫生要求

| 设备类型 | 要求 |
|:---------|:-----|
| 安装要求 | 二次供水设施**宜设有安装消毒设备的位置**。除无负压给水设备和进水中游离氯大于 0.4mg/L 的水箱(池)外，应安装消毒设备 |
| 紫外线消毒器 | 应符合 GB 28235-2020 规定，应具备机械清洗装置，石英套管结垢系数不应低于规定值 |
| 二氧化氯消毒剂发生器 | 应符合 GB 28931 规定 |
| 次氯酸钠发生器 | 应符合 GB 28233 规定 |
| 臭氧消毒器 | 应符合 GB 28232 规定 |

## 7 运营要求

### 7.1 运营单位与人员要求

| 要求 | 内容 |
|:-----|:-----|
| 管理职责 | 运营单位负责二次供水设施的巡查、运行、维护、清洗、消毒等日常管理工作 |
| 制度建设 | 制定管理、维护、水箱(池)清洗、消毒、水质检测等制度和突发水污染事故应急处置预案 |
| 人员配置 | 应配备**专(兼)职管水人员**，明确工作职责 |
| 健康培训 | 管水人员**每年应进行健康检查、卫生知识培训和应急演练** |

### 7.2 管理档案

运营单位应设置二次供水设施管理档案，包括：
- 设施的基础性资料
- 管理制度和专(兼)职管水人员名单
- 涉及饮用水卫生安全产品的卫生许可批件或卫生学评价报告
- **水箱(池)清洗和消毒记录**
- **水质检测档案**
- 水箱(池)巡查记录
- 消毒设备的使用维护记录
- 紫外线灯管更换记录
- 管水人员的健康检查和相关培训记录
- 应急演练记录

### 7.3 水箱(池)清洗、消毒要求

| 要求 | 内容 |
|:-----|:-----|
| 清洗频次 | **每年不少于1次** |
| 特殊情况 | 正常运营期间水质检测结果不符合 GB 5749-2022 规定时，应立即对水箱(池)进行清洗、消毒 |
| 人员要求 | 从事水箱(池)清洗、消毒工作的人员**上岗前应进行健康体检和相关培训** |
| 消毒剂要求 | 使用的消毒剂应符合《生活饮用水消毒剂和消毒设备卫生安全评价规范(试行)》规定 |
| 记录要求 | 清洗、消毒后应做好**记录** |

### 7.4 水质检测要求

#### 7.4.1 检测频次

- 正常运营期间**每年不应少于1次**

#### 7.4.2 必测指标

| 序号 | 指标分类 | 指标名称 |
|:-----|:---------|:---------|
| 1 | 常规指标 | 菌落总数、总大肠菌群、大肠埃希氏菌（当检出总大肠菌群时）、色度、浑浊度、臭和味、肉眼可见物、pH、氨(以N计)、高锰酸盐指数 |
| 2 | 消毒剂及消毒副产物 | 根据消毒方式（氯胺/次氯酸钠/臭氧/二氧化氯）检测相应指标 |
| 3 | 其他指标 | 根据情况选择相应指标 |

#### 7.4.3 增测指标情形

| 情形 | 增测指标 |
|:-----|:---------|
| 初次使用前或长期停用恢复供水前 | GB 5749-2022 表1中的指标（除放射性指标外） |
| 维修维护后 | 因设施维修维护导致水质变化的相关指标 |
| 清洗、消毒后 | 阴离子合成洗涤剂和消毒剂对应的消毒剂及消毒副产物指标 |
| 水质污染事件恢复供水前 | GB 5749-2022 表1、表3中与水质污染相关的指标 |
| 其他影响水质的情况 | 根据情况选择相应指标 |

#### 7.4.4 检测结果要求

- 水质指标检测结果应符合 **GB 5749-2022** 的规定
- 安装消毒设备的二次供水设施应满足消毒剂指标要求
