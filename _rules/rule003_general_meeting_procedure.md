---

## 第一章 总则

### 第一条 【制定目的】

为规范翡翠山城别墅区业主大会的活动，维护全体业主的合法权益，保障物业管理区域内物业管理的正常运行，根据《中华人民共和国民法典》《物业管理条例》《广东省物业管理条例》《惠州市物业管理条例》及相关法律法规，结合本小区实际情况，制定本规则。

### 第二条 【适用范围】

本规则适用于翡翠山城别墅区（含爱丁堡1期、红郡2期）业主大会的组织、召开、表决及业主委员会的选举、履职、监督等活动。

### 第三条 【基本原则】

业主大会活动应当遵循以下原则：

       1. **合法合规原则：** 遵守法律法规，不得损害国家利益、社会公共利益和他人合法权益；
       2. **民主决策原则：** 重大事项由业主共同决定，保障业主的知情权、参与权、表达权和监督权；
       3. **公开透明原则：** 会议召集、议题确定、表决过程、结果公示全程公开；
       4. **少数服从多数原则：** 在法定参与比例和表决比例框架内形成有效决议；
       5. **权责对等原则：** 业主享有权利的同时应当履行业主义务。

### 第四条 【业主大会性质】

业主大会由物业管理区域内全体业主组成，代表和维护全体业主在物业管理活动中的合法权益，是小区物业管理的最高决策机构。

**业主大会依法决定下列事项：**

| 序号 | 事项 | 法律依据 | 表决要求 |
|:----:|:-----|:---------|:---------|
| 1 | 制定和修改业主大会议事规则 | 《民法典》第278条第1款 | 双2/3参与 + 双过半同意 |
| 2 | 制定和修改管理规约 | 《民法典》第278条第2款 | 双2/3参与 + 双过半同意 |
| 3 | 选举业主委员会或者更换业主委员会成员 | 《民法典》第278条第3款 | 双2/3参与 + 双过半同意 |
| 4 | 选聘和解聘物业服务企业 | 《民法典》第278条第4款 | 双2/3参与 + 双过半同意 |
| 5 | 使用建筑物及其附属设施的维修资金 | 《民法典》第278条第5款 | 双2/3参与 + 双过半同意 |
| 6 | 筹集建筑物及其附属设施的维修资金 | 《民法典》第278条第6款 | 双2/3参与 + 双3/4同意 |
| 7 | 改建、重建建筑物及其附属设施 | 《民法典》第278条第7款 | 双2/3参与 + 双3/4同意 |
| 8 | 改变共有部分的用途或者利用共有部分从事经营活动 | 《民法典》第278条第8款 | 双2/3参与 + 双3/4同意 |
| 9 | 有关共有和共同管理权利的其他重大事项 | 《民法典》第278条第9款 | 双2/3参与 + 双过半同意 |

> **术语说明：**
> - **"双2/3参与"**：指应当由专有部分面积占比三分之二以上的业主且人数占比三分之二以上的业主参与表决；
> - **"双过半同意"**：指应当经参与表决专有部分面积过半数的业主且参与表决人数过半数的业主同意；
> - **"双3/4同意"**：指应当经参与表决专有部分面积四分之三以上的业主且参与表决人数四分之三以上的业主同意。

## 第二章 业主大会会议

### 第五条 【会议类型】

业主大会会议分为**定期会议**和**临时会议**。

| 会议类型 | 召开条件 | 召集人 | 通知期限 |
|:---------|:---------|:-------|:---------|
| **定期会议** | 每年至少召开一次，原则上于每年第一季度召开 | 业主委员会 | 会议召开15日前 |
| **临时会议** | 符合第六条情形之一 | 业主委员会/提议业主/街道办事处 | 会议召开15日前 |

### 第六条 【临时会议召集条件】

有下列情形之一的，应当召开业主大会临时会议：

       1. 经专有部分占建筑物总面积20%以上且占总人数20%以上的业主联名书面提议的；
       2. 发生重大事故或者紧急事件需要及时处理的；
       3. 业主委员会成员人数不足总数的二分之一的；
       4. 业主委员会决定召集的；
       5. 街道办事处或者区住房和建设局要求召开的；
       6. 业主大会议事规则或者管理规约规定的其他情形。

### 第七条 【会议形式】

本小区业主大会会议采用**"微信群议事 + 粤省事电子投票"**的线上线下结合形式。

| 环节 | 形式 | 平台/渠道 | 法律效力 |
|:-----|:-----|:----------|:---------|
| **议题讨论** | 微信群线上讨论 | 业主大会微信群 | 议事参考，非法定表决 |
| **身份核验** | 电子平台自动核验 | 粤省事（对接不动产登记） | 法定身份确认 |
| **正式表决** | 电子投票 | 粤省事"业主决策电子投票" | 法定表决效力 |
| **结果公示** | 网站+微信群+公告栏 | GitHub Pages + 微信群 + 公告栏 | 法定公示效力 |
| **异议处理** | 书面申请 | 业委会邮箱/办公室 | 法定救济渠道 |

> **重要提示：** 微信群讨论仅为议事环节，**不具有表决效力**。正式表决必须通过粤省事等经住建部门认可的电子投票系统进行。

### 第八条 【会议通知】

#### 8.1 通知内容

会议通知应当包括：

1. 会议召开的时间、形式（微信群议事起止时间、电子投票起止时间）；
2. 会议议题、议程及具体内容（附详细方案文档链接）；
3. 表决事项及表决规则；
4. 粤省事电子投票操作指南；
5. 微信群议事规则（发言规范、禁言时段）；
6. 会务联系人及联系方式；
7. 异议渠道和时限。

#### 8.2 通知方式与送达确认

| 方式 | 具体操作 | 送达确认 | 优先级 |
|:-----|:---------|:---------|:------:|
| **微信群公告** | 由业委会主任发布群公告，@全体成员 | 保留群公告截图、阅读人数记录 | ★★★ |
| **微信公众号推送** | 通过小区公众号发布图文通知 | 保留推送记录、阅读量 | ★★★ |
| **短信通知** | 向预留手机号发送短信（含投票链接） | 保留短信平台发送回执 | ★★☆ |
| **公告栏张贴** | 在小区主要出入口、各楼栋单元门口张贴 | 拍照存档，记录时间地点 | ★★☆ |
| **网站公示** | 在GitHub Pages公示站发布 | 保留网页快照 | ★★☆ |
| **电话通知** | 对老年业主、长期未参与业主电话通知 | 记录通话时间、内容 | ★☆☆ |

> **送达规则：** 以上方式**同时采用三种以上**即视为有效送达。微信群公告发布后即视为送达，业主未查看不影响会议效力。

### 第九条 【业主参会资格与身份核验】

#### 9.1 业主认定

以不动产登记簿记载的权利人为准。尚未办理产权登记的，以购房合同记载的买受人为准。

#### 9.2 电子投票身份核验

| 平台 | 核验方式 | 说明 |
|:-----|:---------|:-----|
| **粤省事** | 人脸识别 + 不动产登记数据自动比对 | 业主本人操作，系统自动确认业主身份和专有部分面积 |
| **备用平台** | 依各地住建部门指定平台 | 须具备与不动产登记系统对接能力 |

> **核验失败处理：** 如业主在粤省事无法通过身份核验，应当：
> 1. 联系业委会核实房产登记信息是否准确；
> 2. 信息有误的，由业委会协助向不动产登记中心申请更正；
> 3. 系统故障的，采用书面征求意见形式作为补充。

#### 9.3 委托投票

业主可以委托代理人代为投票，但应当通过**粤省事平台的委托投票功能**或**书面委托书**办理。

| 委托方式 | 要求 | 限制 |
|:---------|:-----|:-----|
| **电子委托** | 业主在粤省事发起委托，受托人接受 | 同一受托人最多接受3户委托 |
| **书面委托** | 提交经公证或业委会核验的委托书 | 须在投票开始前3日提交业委会备案 |

> **禁止代理情形：** 筹集维修资金、改建重建建筑物、选聘解聘物业企业等重大事项，原则上应当由业主本人投票。确需委托的，须经业委会审核同意。

### 第十条 【业主投票权】

#### 10.1 投票权计算

| 计算方式 | 说明 | 数据来源 |
|:---------|:-----|:---------|
| **面积票权** | 以不动产登记簿记载的专有部分建筑面积为准 | 粤省事平台自动读取不动产登记数据 |
| **人数票权** | 一个专有部分按一人计算 | 粤省事平台自动统计 |

#### 10.2 特殊情形

| 情形 | 投票权处理 |
|:-----|:-----------|
| 车位、摊位等特定空间 | 不计入投票权数 |
| 建设单位未出售车位 | 不计入投票权 |
| 同一买受人多个专有部分 | 按一人计算 |
| 房屋空置 | 不影响投票权 |
| 欠缴物业费 | 不影响投票权，但可能影响业委会候选人资格 |

## 第三章 业主大会表决

### 第十一条 【表决方式】

#### 11.1 法定表决方式

本小区业主大会表决采用**粤省事电子投票**为主，**书面征求意见**为辅的方式。

| 方式 | 适用情形 | 要求 |
|:-----|:---------|:-----|
| **粤省事电子投票** | 所有常规表决事项 | 业主通过粤省事APP/小程序完成身份核验和投票 |
| **书面征求意见** | 电子投票系统故障、老年业主无法使用电子平台 | 按《操作手册》纸质流程执行 |
| **应急决议** | 危及安全的紧急情况 | 业委会先行决定，事后电子投票追认 |

#### 11.2 表决意见

表决票应当设置以下选项：

| 选项 | 含义 | 计票规则 |
|:-----|:-----|:---------|
| **同意** | 赞成该表决事项 | 计入同意票 |
| **反对** | 不赞成该表决事项 | 计入反对票 |
| **弃权** | 放弃表决权利 | 计入参与表决人数/面积，但不计入同意或反对 |
| **未参与** | 未在规定时间内提交表决票 | 不计入参与表决基数 |

> **禁止事项：** 表决票不得设置"同意多数意见""随大流"等模糊选项；不得诱导、胁迫业主作出特定选择。

### 第十二条 【表决程序】

#### 12.1 表决流程

```
│   至投票前）  │
└──────┬──────┘
       │
       ▼
┌─────────────┐
│  粤省事平台   │
│  开启投票     │
│  （通常5-15日）│
└──────┬──────┘
       │
       ▼
┌─────────────┐
│  系统自动     │
│  计票统计     │
└──────┬──────┘
       │
       ▼
┌─────────────┐

```

> **优先采用电子投票**：鼓励业主通过粤省事等政府认可的平台进行投票，全程留痕、不可篡改。若电子投票参与率未达法定比例，启动纸质投票作为补充。


#### 12.2 微信群议事规则

微信群议事是正式投票前的重要环节，应当遵守以下规则：

| 项目 | 要求 |
|:-----|:-----|
| **议事时间** | 正式投票开始前7日至投票结束前1日 |
| **发言规范** | 围绕议题发言，文明表达，禁止人身攻击 |
| **信息推送** | 业委会每日推送议题说明、FAQ、操作指南 |
| **问题收集** | 业主提问由业委会统一收集，24小时内集中答复 |
| **禁言时段** | 每日22:00-次日8:00为静默时段，业委会不发工作消息 |
| **言论效力** | 微信群发言仅为意见表达，**不构成表决** |

> **微信群管理：** 详见《翡翠山城别墅区业主大会微信群规范》。

#### 12.3 电子投票管理

| 环节 | 管理要求 |
|:-----|:---------|
| **投票开启** | 由业委会在粤省事平台发起，设定投票起止时间 |
| **投票期限** | 一般事项5-7日，重大事项7-15日 |
| **中途提醒** | 投票截止前3日、前1日，微信群提醒未投票业主 |
| **实时查询** | 业主可在粤省事查询本人投票状态，但**不公开实时票数** |
| **投票截止** | 系统自动关闭投票通道，任何人无法继续投票 |
| **数据导出** | 业委会从粤省事后台导出投票明细（脱敏），作为计票依据 |

> **保密规则：** 投票期间，业委会不得向任何人透露实时投票情况，避免影响业主独立判断。

### 第十三条 【表决结果统计】

#### 13.1 统计方式

| 项目 | 计算方式 | 数据来源 |
|:-----|:---------|:---------|
| **参与率（面积）** | 参与表决业主专有部分面积之和 ÷ 小区专有部分总面积 | 粤省事平台自动计算 |
| **参与率（人数）** | 参与表决业主人数 ÷ 小区业主总人数 | 粤省事平台自动计算 |
| **同意率（面积）** | 同意业主专有部分面积之和 ÷ 参与表决业主专有部分面积之和 | 粤省事平台自动计算 |
| **同意率（人数）** | 同意业主人数 ÷ 参与表决业主人数 | 粤省事平台自动计算 |

#### 13.2 有效性判定

| 判定标准 | 要求 |
|:---------|:-----|
| **会议有效** | 面积参与率 ≥ 2/3 且 人数参与率 ≥ 2/3 |
| **决议通过（一般事项）** | 会议有效，且面积同意率 > 1/2 且 人数同意率 > 1/2 |
| **决议通过（重大事项）** | 会议有效，且面积同意率 ≥ 3/4 且 人数同意率 ≥ 3/4 |
| **决议不通过** | 未达到上述比例 |

> **系统优势：** 粤省事平台自动校验参与率和同意率，实时判定会议有效性，避免人工计算错误。

### 第十四条 【表决结果公示】

#### 14.1 公示内容

| 内容 | 要求 |
|:-----|:-----|
| **会议基本情况** | 召开时间、形式、议题、投票起止时间 |
| **参与情况** | 应参与户数/面积、实际参与户数/面积、参与率 |
| **表决结果** | 同意户数/面积及比例、反对户数/面积及比例、弃权户数/面积及比例 |
| **决议效力** | 是否达到法定比例、决议是否通过 |
| **平台验证** | 附粤省事平台出具的投票结果截图或报告 |
| **异议渠道** | 公示期限、异议提交方式、处理程序 |

#### 14.2 公示要求

| 项目 | 要求 |
|:-----|:-----|
| **公示期限** | 不少于7日 |
| **公示方式** | 微信群公告、GitHub Pages公示站、小区公告栏 |
| **数据脱敏** | 公示统计结果，不公开具体房号、业主姓名 |
| **异议处理** | 公示期内接受书面异议，10个工作日内答复 |

## 第四章 业主委员会

（同原版，略作调整以适应线上工作模式）

### 第十五条 【业委会组成】

| 职务 | 人数 | 产生方式 | 任期 |
|:-----|:----:|:---------|:----:|
| **主任** | 1人 | 业委会会议选举 | 3年 |
| **副主任** | 1人 | 业委会会议选举 | 3年 |
| **委员** | 5人 | 业主大会电子投票选举 | 3年 |
| **候补委员** | 3人 | 业主大会电子投票选举 | 3年 |
| **合计** | **10人** | — | — |

> **区域平衡：** 爱丁堡1期3名委员、红郡2期3名委员、机动1名委员。

### 第十六条 【业委会委员条件】

#### 16.1 积极条件

业主委员会委员候选人应当符合以下条件：

1. 具有完全民事行为能力；
2. 为本小区业主（以不动产登记簿或购房合同为准）；
3. 遵守国家法律法规和本小区管理规约；
4. 热心公益事业，责任心强，公正廉洁；
5. 具有一定的组织能力和必要的工作时间；
6. 未处于失信被执行人名单；
7. 本人及其近亲属未在本小区物业服务企业任职。

#### 16.2 消极条件（不得担任情形）

有下列情形之一的，不得担任业主委员会委员：

| 序号 | 情形 | 说明 |
|:----:|:-----|:-----|
| 1 | 违反管理规约，欠缴物业费超过6个月 | 以物业服务企业书面催缴记录为准 |
| 2 | 违反房屋使用规定，擅自改变房屋用途 | 如将住宅改为群租房、经营性场所 |
| 3 | 损坏房屋承重结构、违法搭建 | 以行政部门认定为准 |
| 4 | 被依法追究刑事责任 | 刑罚执行完毕之日起5年内 |
| 5 | 被业主委员会罢免未满3年 | — |
| 6 | 其他不适宜担任的情形 | 由业主大会认定 |

### 第十七条 【业委会职责】

业主委员会履行以下职责：

| 类别 | 具体职责 |
|:-----|:---------|
| **召集会议** | 召集业主大会会议，报告物业管理实施情况 |
| **签订合同** | 代表业主与物业服务企业签订、变更或解除物业服务合同 |
| **监督物业** | 监督物业服务企业履行合同，考核服务质量 |
| **财务管理** | 管理公共收益，定期公布收支情况 |
| **维修资金** | 组织维修资金的筹集、使用和管理 |
| **纠纷调解** | 调解业主之间、业主与物业之间的纠纷 |
| **档案管理** | 保管业主大会和业委会会议记录、合同文本、财务凭证等 |
| **配合执法** | 配合街道办事处、社区居委会、行政部门做好相关工作 |
| **其他职责** | 业主大会赋予的其他职责 |

### 第十八条 【业委会会议】

#### 18.1 会议召开

| 项目 | 要求 |
|:-----|:-----|
| **定期会议** | 每月至少召开一次，原则上于每月第一个周六 |
| **临时会议** | 经三分之一以上委员提议，或主任认为必要时 |
| **通知期限** | 会议召开3日前通知全体委员 |
| **会议记录** | 专人记录，参会委员签字确认，存档备查 |

#### 18.2 议事规则

| 项目 | 要求 |
|:-----|:-----|
| **出席要求** | 过半数委员出席方可召开 |
| **表决方式** | 一人一票，举手表决或记名投票 |
| **通过标准** | 全体委员过半数同意 |
| **回避制度** | 涉及委员本人利益的，该委员应当回避 |
| **会议公开** | 业委会会议应当邀请社区居委会列席，业主可旁听（涉及个人隐私的除外） |

### 第十九条 【业委会委员罢免】

#### 19.1 罢免条件

业主委员会委员有下列情形之一的，经业主大会会议通过，可以罢免其委员资格：

| 序号 | 情形 |
|:----:|:-----|
| 1 | 不履行业主委员会委员职责，连续三次无故缺席业委会会议 |
| 2 | 利用职务之便谋取私利，侵占公共收益或维修资金 |
| 3 | 泄露业主个人信息，造成严重后果 |
| 4 | 被依法追究刑事责任 |
| 5 | 丧失民事行为能力 |
| 6 | 不再具备本小区业主身份 |
| 7 | 其他严重损害业主共同利益的情形 |

## 第六章 监督与争议解决

### 第二十二条 【业主监督】

业主享有以下监督权利：

| 权利 | 行使方式 |
|:-----|:---------|
| **知情权** | 查阅业主大会档案、业委会会议记录、财务凭证（须预约登记） |
| **质询权** | 向业委会书面提出质询，业委会应当在10个工作日内书面答复 |
| **建议权** | 向业委会或业主大会提出合理化建议 |
| **罢免权** | 联名20%以上业主提议罢免业委会委员 |
| **诉讼权** | 对侵害业主共同利益的行为，依法向人民法院提起诉讼 |

### 第二十三条 【行政监督】

| 监督主体 | 监督内容 | 监督方式 |
|:---------|:---------|:---------|
| **街道办事处** | 业主大会召开程序、业委会选举、重大事项表决 | 列席会议、审查备案材料、责令改正 |
| **区住房和建设局** | 物业服务企业资质、维修资金管理、招投标程序 | 行政检查、行政处罚 |
| **社区居委会** | 业委会日常工作、业主纠纷调解 | 列席会议、协调指导 |

### 第二十四条 【争议解决】

#### 24.1 内部协商

业主之间、业主与业委会之间、业主与物业之间的争议，应当首先通过协商解决。

#### 24.2 调解程序

| 步骤 | 方式 | 期限 |
|:-----|:-----|:-----|
| 第一步 | 向业委会申请调解 | 业委会应当在15日内组织调解 |
| 第二步 | 向社区居委会申请调解 | 居委会应当在30日内完成调解 |
| 第三步 | 向街道办事处申请调解 | 街道办应当在60日内完成调解 |

#### 24.3 司法救济

调解不成的，当事人可以依法向人民法院提起诉讼，或者依据合同约定申请仲裁。
