## 检查概况

2026年5月26日，大亚湾区相关职能部门组成联合执法检查组，对翡翠山城别墅区进行了执法检查。

## 检查结果

### 1. 消防设施问题

| 问题类别 | 具体问题 |
|:---------|:---------|
| 监控室迁移 | 小区消防监控室一期的，转到二期，金迪说是业委会同意的，但拿不出相关手续，在业主的坚持下，消防答复回去查档，根据开发商报建的消防配置进行整改 |
| 程序违法 | 转移监控室未经业主大会同意，金迪物业是没有权力转移的，属于程序违法 |

### 2. 二次供水管理问题

| 问题类别 | 具体问题 |
|:---------|:---------|
| 卫生环境 | 设备表面积尘，现场卫生条件差 |
| 健康证 | 二次供水管理人员健康证存在问题(疑似造假) |
| 清洗记录 | 未能提供规定的水箱清洗记录（按规定每半年清洗一次） |
| 设施周边 | 供水房周边存在污染源, 二次供水房边上就放了二个大型垃圾桶，违反二次供水管理办法 |
| 水箱管理 | 饮用水箱未加盖，存在安全隐患, 老鼠，垃圾进去了怎么办 |
| 设施维护 | 供水房门腐蚀损坏，内部堆放杂物， 不符合二次供水管理规定 |
| 水质检测 | 检测报告为送检形式，业主知情权保障不足，只检7项，二次供水检测普通项应为24项，常规测为42项，国检为108项内容 |
| 公示情况 | 水质检测报告未向业主公示 |

**执法文书**：卫生监督部门已当场开具《卫生监督意见书》及《行政执法文书》，当场签字

### 3. 物业服务质价不符

- 二期岗亭撒销减少二人，一期监控室私自牵移二期又减二人，保安上岗证只有12人有
- 根据惠州市物业等级收费办法规定，别墅区要配100-150户配一名管家，小区746户应配五个管家，而金迪只配了二个，根据当初业委会公布的物定管理附件每二十户配一名管家，未落实，但管理费一分没减，质价不符
- 在我们选聘的大品牌物业费用都可以降到三块，并且免公摊费

### 4. 公共收益公示

| 问题类别 | 问题描述 |
|:---------|:---------|
| 涉嫌造假 | 金迪物业在公示公共收益涉嫌造假，根据民法典的规定，公共收益归全体业主所有 |
| 业主知情 | 金迪物业说有公布但参与的业主从未看到过 |

## 5. 检查意外事件

- 金迪物业态度极差，现场威胁政府要到上级投诉，到纪委举报，威胁业主，现场安排人来搅局，并动手打人，已报警处理, 警方已立案, 已作行政处罚决定

- 在此次执法检查中，金迪物业已提前知晓本次检查，并做了准备的，加岗加人，总部都派出人员支援，小区一切装修全部停工，但仍被业主查出管理存在的问题及不足
